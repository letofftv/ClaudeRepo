# ffmpeg-skill

- **Ссылка:** https://github.com/kajisho5/ffmpeg-skill
- **Что это:** навык, плагин и MCP-сервер для Claude Code поверх ffmpeg — 42 инструмента монтажа и отделки
- **Найдено:** 2026-10-27, подборка лучших навыков для видеомонтажа
- **Статус:** взять

## Зачем фабрике

- Нарезка, поиск тишины и сцен, **субтитры со стилями ASS** (шрифт
  подбирается по письменности — кириллица учтена), кадрирование 9:16,
  громкость, цвет и LUT (.cube), экспорт под площадки, проверка результата.
- Это отделка поверх фермы, а не замена: ферма рендерит, ffmpeg-skill
  доводит субтитры, звук и экспорт.
- Работает и на маке, и на сервере (нужен только ffmpeg, Python без пакетов).

## Риски и оговорки

- MIT, ~3,1 тыс. ★, активен (2026-10-26).
- Хуков в plugin.json нет; в скриптах и MCP нет сетевых вызовов. Модели
  речи (parakeet-mlx, faster-whisper) скачиваются при первом запуске — на
  фабрике уже есть свой Whisper.
- Вес: 1 навык (~220 строк); MCP по умолчанию показывает 12 инструментов,
  все 42 — через `FFMPEG_SKILL_MCP_FULL=1`.

## Как подключить

```
claude plugin marketplace add kajisho5/ffmpeg-skill
claude plugin install ffmpeg-skill@ffmpeg-skill
```
На маке: `brew install ffmpeg-full`. Перед установкой — SkillSpector.
