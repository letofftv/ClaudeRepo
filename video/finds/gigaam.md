# GigaAM v3

- **Ссылка:** https://github.com/salute-developers/GigaAM
- **Что это:** модель распознавания русской речи от Сбера
- **Найдено:** 2026-10-26, исследование субтитров
- **Статус:** позже — на фабрике уже есть Whisper large-v3 на видеокарте; GigaAM нужен, только если точность Whisper на русском не устроит

## Зачем фабрике

- По замерам авторов выигрывает у Whisper large-v3 в 70% сравнений на
  русском — точнее субтитры и меньше ручной правки.
- С 2026-04 отдаёт тайминги слов — нужно для субтитров.
- 220M–600M параметров, torch ≥2.6 — работает со сборкой cu126 на этой карте.
- MIT.

## Риски и оговорки

- Один вызов `transcribe` — до 25 с аудио; длиннее нужна нарезка (через
  pyannote или по паузам).
- Интеграции с HyperFrames/Orkas нет — нужна обёртка, отдающая субтитры в
  нужном формате.
- Только русский — для английских роликов оставить whisper.cpp.
- Требует PyTorch (≤2.14 cu126).

## Как подключить

После A/B whisper.cpp: если русская точность Whisper не устроит — сделать
обёртку GigaAM → субтитры для HyperFrames.

## Что проверено

README репозитория (прочитан в исследовании): лицензия, тайминги слов,
ограничение 25 с, результаты сравнения. Не запускалось.
