# video-use

- **Ссылка:** https://github.com/browser-use/video-use
- **Что это:** навык «монтаж разговором» от browser-use: транскрипт по словам → список склеек → рендер с самопроверкой
- **Найдено:** 2026-10-27, подборка лучших навыков для видеомонтажа
- **Статус:** попробовать (после замены транскрипции на свой Whisper)

## Зачем фабрике

Лучший образец процесса агентного монтажа:
- транскрипт по словам → `edl.json` (список склеек);
- `timeline_view` — картинки только в спорных местах;
- `render.py` с 30-мс фейдами, `grade.py` — цвет через ffmpeg;
- субтитры последним слоем, самопроверка каждой склейки;
- память проекта в `project.md`.

## Риски и оговорки

- MIT, ~30 тыс. ★, хуков нет.
- **Транскрипция только через ElevenLabs Scribe** (облако, платно, звук
  уходит наружу; оплата и доступ из России затруднены). Обойти: заменить
  `helpers/transcribe.py` (~240 строк) адаптером к Whisper large-v3 фабрики.
- Вес: 1 навык (~340 строк) + навык для Manim.

## Как подключить

Клон → symlink в `~/.claude/skills/video-use` → `uv sync`; сначала —
адаптер транскрипции и SkillSpector.
