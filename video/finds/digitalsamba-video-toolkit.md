# digitalsamba claude-code-video-toolkit

- **Ссылка:** https://github.com/digitalsamba/claude-code-video-toolkit
- **Что это:** готовый проект для видео с Claude Code на Remotion: 13 навыков, 15 команд, Python-инструменты с открытыми ИИ-моделями
- **Найдено:** 2026-10-26, из Claude-Code-Video-Toolkit
- **Статус:** позже (брать отдельные части, не весь проект)

## Зачем фабрике

Самое ценное — отдельные навыки и список моделей:

- **`playwright-recording`** (469 строк) — подробный навык записи браузера:
  подсветка курсора, «круги» от кликов, закрытие cookie-баннеров, размеры
  окна, перекодирование в MP4. Пригодится вместе с Playwright MCP.
- **`synthetic-ui-demo`** — ролик без записи экрана: экраны приложения
  пересобираются в React и «проигрываются» со скриптовым курсором и камерой.
  Требует исходников приложения — для чужих платформ подходит частично.
- **Команды:** `/record-demo`, `/generate-voiceover`, `/redub`, `/thumbnail`,
  `/publish` и др.
- **Открытые модели, которые стоит запускать на своей видеокарте:**
  Qwen3-TTS (озвучка), ACE-Step 1.5 (музыка), LTX-2.3 (видео),
  FLUX.2 (картинки), RealESRGAN (апскейл), SadTalker (говорящая голова).
  На GTX 1050 Ti из них реальны Qwen3-TTS (через qwentts.cpp), ACE-Step 1.5
  (режим «≤4 ГБ»), FLUX.2 klein (через stable-diffusion.cpp) и апскейл;
  LTX-2.3 — нет (см. исследование 2026-10-26).

## Риски и оговорки

- MIT, ~2,3 тыс. ★, активно развивается (последний коммит 2026-10-22).
  Хуков в настройках нет.
- **ИИ-инструменты работают только через облачные GPU (Modal или RunPod)** —
  локального режима нет. Docker-образы моделей есть, но чтобы запустить их
  на своей видеокарте, придётся переделывать.
- Построен на Remotion — конфликтует с выбором HyperFrames. Весь проект
  целиком не ставить.
- В составе есть `dewatermark.py` (в т.ч. пресет для видео Sora) — удаление
  водяных знаков. **Не использовать:** это удаление пометок о
  происхождении и чужих знаков.

## Как подключить

Целиком — нет. Скопировать навык `playwright-recording` после проверки
SkillSpector. Список моделей — ориентир для поиска локальных решений.
