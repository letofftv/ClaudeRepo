# Playwright MCP — запись видео

- **Ссылка:** https://github.com/microsoft/playwright-mcp
- **Что это:** официальный MCP-сервер Microsoft: агент управляет браузером и может записывать видео с анимированным курсором
- **Найдено:** 2026-10-26, из Claude-Code-Video-Toolkit
- **Статус:** попробовать (ключевое для обучающих видео) — сравнить с тем, как ферма снимает интерфейсы сейчас (неизвестно)

## Зачем фабрике

Основа для обучающих роликов по интерфейсам **настоящих** платформ:

- `browser_start_video` — запись WebM; параметр `cursor` рисует анимированный
  курсор, который едет к каждой точке действия (действия замедляются на
  800 мс, чтобы было видно движение). Задаются размер и fps.
- `browser_start_recording` / `browser_stop_recording` — владелец один раз
  проходит сценарий руками, агент получает его как код Playwright, а потом
  чисто воспроизводит и записывает. Удобно для повторяемых дублей.
- Работает по структуре страницы, без моделей зрения — надёжно и дёшево.

Дальше запись идёт в HyperFrames: зум, выноски, субтитры, озвучка.

## Риски и оговорки

- Apache-2.0, Microsoft, ~38,7 тыс. ★, активно развивается.
- Инструменты видео — опция: включаются флагом `--caps=devtools`.
- Флаг `--save-video` из подборки Claude-Code-Video-Toolkit устарел —
  сейчас запись делается инструментом `browser_start_video`.
- Вход на платформы: использовать отдельные учебные аккаунты, пароли
  передавать через механизм `secrets` в конфиге, а не в промпте. В кадр не
  должны попадать личные данные. Учитывать правила платформ об автоматизации.
- Запись в WebM — для монтажа может понадобиться перекодирование в MP4.

## Как подключить

На сервере фабрики:

```
claude mcp add playwright -- npx @playwright/mcp@latest --caps=devtools
```

Первая проба: записать 30–60 секунд одного сценария на знакомой платформе с
`cursor: true`, потом собрать ролик в HyperFrames.
