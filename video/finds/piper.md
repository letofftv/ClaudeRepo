# Piper (piper-tts)

- **Ссылка:** https://github.com/OHF-Voice/piper1-gpl (голоса — Hugging Face `rhasspy/piper-voices`)
- **Что это:** лёгкий локальный синтез речи на ONNX, работает на процессоре; есть русские голоса
- **Найдено:** 2026-10-26, исследование озвучки (как часть Speaches); 2026-10-28 — запрос оператора сервера на озвучку без сервера
- **Статус:** **взять** — для черновой озвучки (стоит на сервере, инструмент пульта `tts_piper`; основная озвучка — Silero v5)

## Зачем фабрике

- **Черновая озвучка за секунды:** текст сцены → WAV, чтобы собрать
  тайминг ролика до настоящего голоса.
- **Без сервера и видеокарты:** ONNX на процессоре, на сервере — в 5 раз
  быстрее реального времени (замер ниже). Видеопамять остаётся ферме и
  Whisper.
- **Русские голоса:** irina, denis, dmitri, ruslan. Качество среднее —
  ниже Silero v5 (основная озвучка, `silero-tts.md`) и omnivoice.cpp.
- **В пульте** — инструмент `tts_piper` (`app/tools/tts_piper.py`):
  - абзацы разделяются паузой, переносы строк внутри абзаца склеиваются;
  - темп от 0,5 до 2;
  - модель голоса загружается один раз на задачу.

## Риски и оговорки

- **Лицензии.** Движок piper-tts — GPL-3.0-or-later; запуск отдельным
  процессом лицензию на ролики не переносит. У каждого голоса своя
  лицензия (MODEL_CARD рядом с файлами), часть — некоммерческие; пока ролики
  не монетизируются, допустимо.
- **Пересечения.** Основная русская озвучка — Silero v5, клон голоса —
  omnivoice.cpp. Piper — запасной и быстрый вариант, не третий основной.
  Speaches (OpenAI-совместимый сервер с Piper) не нужен: обёртка вызывает
  Piper напрямую.
- **Загрузки.** Голоса лежат на Hugging Face. Если сервер его не видит —
  скачать на маке оба файла голоса (`.onnx` и `.onnx.json`) и скопировать.
- **Вес.** Голос medium — десятки мегабайт [оценка], зависимости —
  onnxruntime. Хуков и сетевых вызовов при синтезе нет (код CLI прочитан).

## Как подключить

На сервере уже стоит (2026-10-28). Установка с нуля:

```
pipx install piper-tts
~/.local/share/pipx/venvs/piper-tts/bin/python -m piper.download_voices ru_RU-irina-medium --data-dir ~/hub-work/models/piper
```

Папка голосов — переменная `piper_voices` в `config/tools.local.json`, по
умолчанию `<рабочая папка>/models/piper`. Проверить — `tts_piper` на двух
абзацах.

## Что проверено

- **По исходникам `src/piper/__main__.py` и `setup.py` (ветка `main`,
  версия 1.8.0):**
  - есть команда `piper`;
  - флаги `-m`, `-i`, `-d`, `--length-scale`, `--sentence-silence`, `-s`;
  - при `-d` пишется по WAV на строку;
  - голоса качаются через `piper.download_voices` с Hugging Face.
- **Обёртка** проверена тестом на поддельном `piper`: три абзаца → один WAV
  с паузами, темп → `--length-scale`.
- **Оператором на сервере** (2026-10-28, пульт 0.4.0): `tts_piper` с голосом
  `ru_RU-irina-medium` — два абзаца, 18,4 с речи за 3,4 с.
- **Не проверено:** звучание русских голосов владелец ещё не оценивал;
  denis, dmitri и ruslan не скачаны.
