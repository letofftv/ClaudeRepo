# auto-editor

- **Ссылка:** https://github.com/WyattBlue/auto-editor
- **Что это:** CLI, который вырезает тишину и неподвижные участки и выгружает таймлайн в монтажки; с официальными навыками для агентов
- **Найдено:** 2026-10-27, подборка лучших навыков для видеомонтажа
- **Статус:** взять

## Зачем фабрике

- Грубая резка записей экрана для обучающих роликов: паузы и «пустые»
  участки уходят автоматически.
- **Экспорт таймлайна** `--export premiere` (а также Resolve, FCP, Shotcut,
  Kdenlive) — ложится в нынешний XML-путь фермы.
- Встроенный whisper.cpp и резка по словам (`--edit word`).
- Работает на маке и сервере, без видеокарты.

## Риски и оговорки

- Код Unlicense, но **часть функций за платным ключом**: без ключа рендер
  до 3200×1800 (1080×1920 проходит), рендер из нескольких источников — до
  720×576; экспорт таймлайна из нескольких источников и действие `add` —
  только с ключом (проверка офлайн). Купить ключ из России, вероятно, сложно.
- В pip больше не публикуется — ставить через brew или бинарник.
- 4 навыка (~510 строк) — копируются из `skills/` вручную, манифеста
  плагина нет.

## Как подключить

```
brew install auto-editor
```
Навыки — скопировать нужные из `skills/` в `~/.claude/skills/` после
SkillSpector.
