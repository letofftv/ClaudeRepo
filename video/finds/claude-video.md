# claude-video (`/watch`)

- **Ссылка:** https://github.com/bradautomates/claude-video
- **Что это:** плагин Claude Code, который даёт агенту «смотреть» видео — выборка ключевых кадров и смен сцен плюс транскрипт
- **Найдено:** 2026-10-27, подборка лучших навыков для видеомонтажа
- **Статус:** взять

## Зачем фабрике

- Claude видит готовые рендеры, референсы и чужие обучающие ролики:
  кадры по ключевым кадрам или сменам сцен (лимит 50–100), дубли
  отсеиваются; транскрипт — из субтитров или локального WhisperX.
- Закрывает пробел «видеопроверки»: автопроверка «лука» фермы может
  опираться на то, что агент реально видит в рендере.

## Риски и оговорки

- MIT, ~19,4 тыс. ★, проверен автором на Apple Silicon.
- Один SessionStart-хук — только запускает `setup.py --check` и всегда
  завершается с кодом 0.
- **Облако — по выбору:** движок Gemini загружает файл в Google; Groq и
  OpenAI — для транскрипции. Держать локальный движок.
- WhisperX тянет PyTorch — запускать на маке, не на сервере с 1050 Ti.
- Вес: 1 навык (~170 строк) и 1 хук.

## Как подключить

```
claude plugin marketplace add bradautomates/claude-video
claude plugin install watch@claude-video
```
Перед установкой — SkillSpector; в настройках выбрать локальный движок.
