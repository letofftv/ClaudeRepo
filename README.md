# ClaudeRepo — песочница находок для домашней фабрики

Сюда приносятся новинки — репозитории, навыки и плагины для Claude Code,
MCP-серверы, видео с советами. Здесь их разбирают и оценивают **до** того,
как что-то попадёт на фабрику: польза, лицензия, безопасность, вес для
агента. Правила и контекст фабрики — в [`CLAUDE.md`](CLAUDE.md).

## Направления

| Направление | Что внутри |
|---|---|
| 🎬 [Видеомонтаж](video/README.md) | монтаж, запись экрана для обучающих роликов, субтитры, озвучка, апскейл |
| ✨ [Анимация и мультипликация](animation/README.md) | моушн-графика, рендер сцен кодом, ИИ-картинки и видео, 3D, «живописный 2.5D» |
| 🎚️ [Аудио и мастеринг](audio/README.md) | музыка, сведение, мастеринг, вокал под минусовку, Ableton и MCP, свой пакет навыков |
| 💻 [Программирование и вайбкодинг](coding/README.md) | навыки, плагины, MCP и репозитории для работы с кодом в Claude Code |
| 🗂️ [Организация работы](productivity/README.md) | задачи, заметки, документы, календарь, почта, встречи |
| 🏢 [Цифровизация бизнеса](business/README.md) | автоматизация, CRM, продажи, аналитика, боты, российская экосистема |
| 🧰 [Общее](common/README.md) | проверка навыков (SkillSpector), настройка сервера, сборки общего назначения |

В каждом направлении: индекс с лучшим и статусами находок, папка `finds/`
с карточками и `research/` с отчётами.

## Статусы

**взять** — использовать · **попробовать** — проверить на фабрике ·
**позже** — может пригодиться · **отклонено** — не брать (причина в карточке).

## Свои пакеты навыков

Плагины Claude Code из этого репозитория:

```
claude plugin marketplace add letofftv/ClaudeRepo
claude plugin install music-studio@clauderepo     # аудио и мастеринг
```

## Связь с фабрикой

Пакеты для Claude, который разрабатывает фабрику клипов, — в
[`handoff/`](handoff/README.md).

Репозиторий публичный: ключей, паролей, адресов и личных данных здесь нет.
