# Общее

То, что не относится к одному направлению: проверка безопасности находок,
сборки для Claude Code общего назначения, настройка сервера фабрики,
бесплатные ресурсы для контента. Приложение «Домашний пульт» лежит в
[`app/`](../app/README.md).

## Находки

| Находка | Для чего | Статус | Карточка |
|---|---|---|---|
| SkillSpector (NVIDIA) | проверка навыков на уязвимости перед установкой | **взять** | [skillspector.md](finds/skillspector.md) |
| everything-claude-code (ECC) | сборка для разработки программ — перенесена в [`coding/`](../coding/README.md) | отклонено | [everything-claude-code.md](../coding/finds/everything-claude-code.md) |
| Beszel | история сервера за 30 дней, графики по контейнерам, оповещения; агент для Windows видит хост | **попробовать** | [beszel.md](finds/beszel.md) |
| Dozzle | логи контейнеров в браузере, ссылка из панели пульта | **попробовать** | [dozzle.md](finds/dozzle.md) |
| LibreHardwareMonitor | датчики Windows-хоста по HTTP (температура ЦП, которой не видно из WSL) | **попробовать** | [librehardwaremonitor.md](finds/librehardwaremonitor.md) |

Панель состояния сервера — в «Домашнем пульте» ([`app/`](../app/README.md),
раздел «Сервер»). Почему своя, а не готовая, и какие пороги взяты — в
[исследовании инструментов для интерфейсов](../coding/research/2026-10-28-ui-tools.md#3-панели-мониторинга-домашнего-сервера).

## Бесплатные ресурсы для контента

[free-resources.md](free-resources.md) — 115 бесплатных ресурсов (2026-10-27):

- **ИИ-генерация:** картинки, видео, музыка и звуки, озвучка, тексты,
  обработка;
- **стоки:** видео, фото и искусство CC0, музыка, звуки, сэмплы и импульсы,
  шрифты с кириллицей, иконки и Lottie, 3D и HDRI, LUT и переходы, редакторы.

У каждого ресурса указаны доступ из России, лицензия и пометка
«только некоммерчески». Источник — `app/data/free-resources.json`. Тот же
список есть во вкладке «Ресурсы» [пульта](../app/README.md).

## Переезд сервера на Ubuntu

[`ubuntu-migration/`](ubuntu-migration/README.md) (2026-10-28) — план
переезда с WSL2 на Ubuntu Server 24.04 на втором SSD с откатом в Windows:

- решения и шаги владельца;
- промпты для Claude на сервере «до» (опись, замеры, резервные копии) и
  «после» (драйвер 580, Docker с видеокартой, восстановление служб, пульт);
- скрипт описи сервера;
- пакет для фабрики.
