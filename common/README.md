# Общее

То, что не относится к одному направлению: проверка безопасности находок,
сборки для Claude Code общего назначения, настройка сервера фабрики,
бесплатные ресурсы для контента. Приложение «Домашний пульт» лежит в
[`app/`](../app/README.md).

## Находки

| Находка | Для чего | Статус | Карточка |
|---|---|---|---|
| SkillSpector (NVIDIA) | проверка навыков на уязвимости перед установкой | **взять** | [skillspector.md](finds/skillspector.md) |
| everything-claude-code (ECC) | сборка для разработки программ — перенесена в [`coding/`](../coding/README.md) | отклонено | [everything-claude-code.md](../coding/finds/everything-claude-code.md) |

## Бесплатные ресурсы для контента

[free-resources.md](free-resources.md) — 115 бесплатных ресурсов (2026-10-27):

- **ИИ-генерация:** картинки, видео, музыка и звуки, озвучка, тексты,
  обработка;
- **стоки:** видео, фото и искусство CC0, музыка, звуки, сэмплы и импульсы,
  шрифты с кириллицей, иконки и Lottie, 3D и HDRI, LUT и переходы, редакторы.

У каждого ресурса указаны доступ из России, лицензия и пометка
«только некоммерчески». Источник — `app/data/free-resources.json`. Тот же
список есть во вкладке «Ресурсы» [пульта](../app/README.md).
