# Dozzle

- **Ссылка:** https://github.com/amir20/dozzle
- **Что это:** веб-просмотр логов Docker-контейнеров в реальном времени, с поиском; логи не хранит
- **Найдено:** 2026-10-28, исследование панелей мониторинга
- **Статус:** попробовать

## Зачем фабрике

Отвечает на вопрос «почему упала служба» прямо с телефона. У каждого
контейнера своя страница `/container/<id>` — на неё можно ссылаться из
списка контейнеров на панели пульта.

## Риски и оговорки

- **Лицензия и размер.** MIT, Go, образ ~7 МБ.
- **Доступ к `docker.sock` равен root.** Только за VPN и с включённой авторизацией.
- **Стабильного API нет** — только глубокие ссылки.

## Как подключить

```
docker run -d --name dozzle -v /var/run/docker.sock:/var/run/docker.sock -p 127.0.0.1:8080:8080 amir20/dozzle
```

Затем добавить ссылку в `links` пульта.
