# everything-claude-code (ECC)

- **Ссылка:** https://github.com/affaan-m/everything-claude-code (теперь `affaan-m/ECC`)
- **Что это:** большая сборка для Claude Code: 71 агент, 311 навыков, 97 команд, 27 хуков (v2.2.3)
- **Найдено:** 2026-10-26, YouTube Shorts @j71a «Сборка Claude Code бесплатно» («скиньте ссылку и попросите всё установить»)
- **Статус:** отклонено

## Зачем фабрике

Почти ни зачем. Сборка рассчитана на разработку программ: TDD, ревью кода,
архитектура, сборка проектов. Для роликов, анимации и обучающих видео в ней
нет ничего, чего не дают точечные инструменты из других карточек.

## Риски и оговорки

- Описания ~380 агентов и навыков подгружаются в каждую сессию — по грубой
  оценке до ~30 тыс. токенов; агенту труднее выбрать нужный навык.
- 27 хуков: 10 перед каждым вызовом инструмента, 8 при каждом завершении
  ответа и др. Это чужие node-скрипты на каждом шаге и замедление работы.
- Команда `/astra-review` отправляет код в OpenAI через Codex CLI.
- Сам README предупреждает: фиксированная версия — не аудит безопасности,
  неофициальные копии могут содержать вредоносный код.
- Лицензия MIT, проект настоящий и популярный (~290 тыс. ★) — дело не в обмане,
  а в том, что «установить всё» вредно.

## Как подключить

Не подключать. Если у фабрики появится свой код (скрипты конвейера и т.п.),
можно вернуться и взять 2–3 отдельных навыка после чтения.

## Что проверено

Репозиторий склонирован и пересчитан: агенты, навыки, команды, список хуков из
`hooks/hooks.json`. Код хуков построчно не читался. Ничего не запускалось.
