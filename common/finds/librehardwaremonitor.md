# LibreHardwareMonitor

- **Ссылка:** https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
- **Что это:** датчики железа Windows (температуры и частоты процессора, вентиляторы, GPU, диски) со встроенным HTTP-сервером `/data.json` и `/metrics`
- **Найдено:** 2026-10-28, исследование панелей мониторинга
- **Статус:** попробовать — до переезда на Ubuntu

## Зачем фабрике

Из WSL2 не видно температуры процессора и вентиляторов, а реальная память
и диски хоста — только частично. LibreHardwareMonitor отдаёт их по HTTP.
Пульт или Beszel могут читать `/data.json`. После переезда на Ubuntu не
нужен: там датчики читаются напрямую (hwmon).

## Риски и оговорки

- **Лицензия и платформа.** MPL-2.0, .NET.
- **Права администратора** нужны части датчиков.
- **Драйвер ядра.** В связке с Beszel ставится драйвер PawnIO — проверить безопасность до установки.
- **HTTP-сервер** открыть только для WSL или подсети VPN, с Basic-авторизацией.

## Как подключить

Релиз с GitHub на Windows-хосте → включить веб-сервер → проверить
`http://<хост>:<порт>/data.json` из WSL. Интеграция с пультом — отдельной
задачей (новые поля в панели «Сервер»).
