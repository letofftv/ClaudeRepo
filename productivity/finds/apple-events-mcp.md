# mcp-server-apple-events

- **Ссылка:** https://github.com/FradSer/mcp-server-apple-events
- **Что это:** MCP-сервер для Напоминаний и Календаря macOS (EventKit, подписанный Swift-бинарник), 5 инструментов
- **Найдено:** 2026-10-27, подборка навыков для организации работы
- **Статус:** попробовать

## Зачем фабрике

Один локальный хаб задач и событий: Яндекс Календарь и iCloud подключаются
в Календарь.app по CalDAV, а Claude работает с ними через EventKit — без
чужих токенов и облачных посредников.

## Риски и оговорки

- MIT, ~230 ★, активен (2026-10-23). Только macOS.
- Разрешения macOS выдаются отдельно каждому приложению.
- Версию в `npx` закреплять.

## Как подключить

```
claude mcp add apple-events -- npx -y mcp-server-apple-events@<версия>
```
