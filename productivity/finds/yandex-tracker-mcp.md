# yandex-tracker-mcp

- **Ссылка:** https://github.com/aikts/yandex-tracker-mcp
- **Что это:** MCP-сервер для Яндекс Трекера — задачи, очереди, комментарии, учёт времени
- **Найдено:** 2026-10-27, подборка навыков для организации работы
- **Статус:** попробовать (если понадобится настоящий трекер с веб- и мобильным интерфейсом)

## Зачем фабрике

Российский трекер задач (бесплатно до 5 пользователей), с которым Claude
может работать: заводить и закрывать задачи, комментировать, учитывать
время. Альтернатива западным Linear/Asana/Notion, недоступным из России.

## Риски и оговорки

- Apache-2.0, ~120 ★, активен (2026-09-06). Телеметрии не найдено.
- Нужны OAuth-токен и ID организации (Яндекс 360 или Cloud).
- ~94 инструмента — много; на первое время `TRACKER_READ_ONLY=true` и
  `TRACKER_LIMIT_QUEUES`.
- Пока задачи фабрики живут в GitHub Issues (`gh`), этот сервер не нужен.

## Как подключить

```
claude mcp add yandex-tracker -- uvx yandex-tracker-mcp@<версия>
```
с переменными токена, организации и `TRACKER_READ_ONLY=true`.
