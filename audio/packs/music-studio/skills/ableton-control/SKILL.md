# Ableton Live через MCP

Состояние на 2026-10-27. Подробное сравнение серверов —
`audio/research/2026-10-27-audio-production.md` в репозитории ClaudeRepo.

## 1. Выбор сервера

**У владельца — Ableton Live 12.4.7 Suite (2026-10-27) → основной сервер
Producer Pal** (нужна 12.3+ — подходит).
LiveBridge — по желанию вторым, для метров, автоматизации и замеров
баунса (порты не конфликтуют: Producer Pal 3350/3349, LiveBridge 9880), но
два сервера — это сотни инструментов в контексте: включать только на время
сведения и мастеринга.

| Что у владельца | Сервер | Почему |
|---|---|---|
| Live 12.3+ **Suite** (или Max for Live) | **Producer Pal** (`adamjmurray/producer-pal`, GPL-3) | самый зрелый: дорожки, клипы, MIDI, аранжировка, take lanes, громкость/пан/посылы, запись; есть отдельная инструкция для Claude Code |
| Live 12 любой редакции, нужна помощь со сведением и мастерингом | **LiveBridge** (`valentijnh/livebridge-ableton-mcp`, MIT) | микс в дБ, шины, сайдчейн, метры, автоматизация, замер LUFS/спектра баунса против референса; параметры VST3 без ручного Configure |
| Нужен осторожный вариант без выполнения кода | **wstierhout/ableton-live-mcp** (MIT) | 156 типизированных инструментов, нет произвольного кода, нет внешних адресов |

**Не использовать как основной:** `ahujasid/ableton-mcp` (телеметрия
включена по умолчанию, мало инструментов), `Simon-Kansara/...` (заброшен,
1 рабочий инструмент), LivePilot (лицензия BSL, ходит в Splice и GitHub).
**Не ставить несколько серверов сразу** — ahujasid, wstierhout и
AbletonBridge слушают один порт 9877.

## 2. Безопасное подключение

- Версию пакета **закреплять** (`npx producer-pal@<версия>`, не `@latest`).
- LiveBridge: запускать с `--no-allow-eval` (иначе включён инструмент
  произвольного Python внутри Live) и `--no-splice`. Его установщик пишет
  навык в `~/.claude/skills` — прогнать через SkillSpector.
- Producer Pal слушает HTTP без авторизации на всех интерфейсах — закрыть
  входящие соединения к Max в брандмауэре macOS.
- AbletonOSC (основа нескольких серверов) по умолчанию слушает `0.0.0.0`
  без авторизации — только в доверенной сети.
- Сужать набор инструментов (`--tools core,clip,track` у Producer Pal,
  `ABLETON_TOOLSETS` у wstierhout): 150–470 инструментов в каждой сессии —
  лишний вес и путаница.
- **Перед каждой сессией — сохранить сет** (Live API не умеет сохранять сам).

Producer Pal в Claude Code (macOS):
```
# Live 12.3+ с Max for Live, Node 20+; Producer_Pal.amxd из релизов — на MIDI-дорожку
claude mcp add producer-pal -- npx producer-pal@<версия> --tools core,clip,track
# в Claude Code: /mcp → проверить подключение → «connect to ableton»
```

## 3. Что Live API не умеет (у любого сервера)

- **Экспорт/рендер, заморозка, сохранение сета** — нет. Экспорт делает
  владелец; потом файл меряется навыком `audio-measure`.
- **Параметры сторонних плагинов** видны, только если добавлены в список
  Configure (максимум 128) или плагин сам укладывается в порог
  автозаполнения. Свежий Serum 2 — 0 из 2 623 параметров. Configure
  сохраняется только в **пресете рэка**, не в пресете плагина.
- **Автоматизация**: у Producer Pal — нет; у LiveBridge — в клипах и записью
  в реальном времени.
- **Слух**: Claude получает только метры и замеры баунсов.
- Комппинг и тюнинг вокала — вручную (Live не поддерживает ARA; Melodyne —
  только как плагин).

## 4. Рецепт: сессия сведения с материалом со студии

Вокал записывается на студии, сведение — на маке (см. навык
`vocal-recording`, раздел «Импорт»).

1. Замерить минусовку (`audio-measure`, `--role beat`), узнать темп и
   тональность (сетка долей фабрики, если есть).
2. Создать дорожки: `Beat`, `Vox Lead`, `Vox Double L/R`, `Adlibs`, `BV`,
   возвраты `Slap`, `Delay`, `Reverb`; группа `Vox Bus`.
3. Выставить темп сета по минусовке; Warp на минусовке включить, **на
   вокальных файлах — выключить**. Файлы со студии — на 1.1.1.
4. На `Beat` — Utility с понижением громкости по замеру (для пережатых
   минусовок 6–10 дБ).
5. Цепочки обработки — по навыку `vocal-over-beat` (в Suite доступны Roar,
   Hybrid Reverb и Stem Separation).
6. После каждой правки громкости — словами сказать владельцу, что
   изменилось, и попросить послушать.

## 5. Сведение через параметры

- Встроенные устройства Live отдают все параметры с понятными именами —
  предпочитать EQ Eight, Compressor, Glue Compressor, Utility, Saturator,
  Auto Shift, Echo, Reverb/Hybrid Reverb.
- Значения в API часто нормированы (0…1) — перед записью параметра читать
  min/max и строку отображения, менять малыми шагами.
- Простые плагины с короткими списками параметров (Trackspacer,
  LALA/FETish, T-De-Esser 2, Valhalla, LoudMax) удобнее для агента, чем
  Serum, Ozone или Pro-Q 4 с сотнями параметров.

## Если владелец работает не в Ableton

- **REAPER** даёт агенту самый глубокий доступ: любые параметры плагинов
  без Configure, рендер, стемы, замер громкости (`bonfire-systems/reaper-mcp`,
  `xDarkzx/Reaper-MCP`); лицензия ~$60.
- **Audition**: официального MCP нет; любительские мосты требуют отключить
  проверку подписи у всех CEP-панелей — не рекомендуется. Обработку делать
  вне Audition (навык `audio-measure`, ffmpeg, Pedalboard).
- **Audacity**: `xDarkzx/Audacity-MCP` (без exec/eval) — для чистки и
  нормализации.
