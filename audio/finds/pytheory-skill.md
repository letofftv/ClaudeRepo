# pytheory-skill

- **Ссылка:** https://github.com/kennethreitz/pytheory-skill (библиотека — pytheory, ~1,7 тыс. ★)
- **Что это:** плагин из 6 навыков по теории музыки: гармония, анализ по ступеням, вторичные доминанты, заимствованные аккорды, голосоведение, экспорт в MIDI и MusicXML
- **Найдено:** 2026-10-27, подборка навыков для музыки
- **Статус:** попробовать — взять 2 навыка (keys-and-harmony, chord-lab)

## Зачем фабрике

Помощь в сочинении: подобрать гармонию к мелодии, разобрать минусовку по
ступеням, предложить заимствованный аккорд, выгрузить в MIDI для Live.

## Риски и оговорки

- MIT, плагин ~3 ★ (2026-06), сама библиотека популярна.
- Хуков нет; данные не собираются. Но **навыки заранее разрешают
  `Bash(python3:*)`** — любой python3 без вопроса; при копировании убрать
  это разрешение.
- Дублирует music21-mcp-server — оставить одно (pytheory легче, без MCP).

## Как подключить

```
/plugin marketplace add kennethreitz/pytheory-skill
uv pip install pytheory
```
Лучше скопировать два нужных навыка в `~/.claude/skills` без широкого
разрешения на python3.
