# ACE-Step 1.5

- **Ссылка:** https://github.com/ace-step/ACE-Step-1.5
- **Что это:** генерация музыки (фон, джинглы, песни с вокалом) с режимом для видеокарт до 4 ГБ
- **Найдено:** 2026-10-26, исследование вспомогательных инструментов
- **Статус:** попробовать (заявления авторов не проверены)

## Зачем фабрике

- Своя фоновая музыка для роликов и клипов без лицензионных рисков стоков.
- В документации по совместимости есть **режим «≤4 ГБ»**: только DiT (без
  языковой модели), INT8, полная разгрузка на CPU, декодирование VAE может
  уйти на процессор, батч 1, до 6 минут аудио. Для карт ниже CC 7.0
  автоматически выбирается PyTorch-бэкенд.
- REST API (`acestep-api`) и CLI — встраивается в конвейер.
- Языков текстов «50+»; у v1 русский был в первой десятке.

- **Для сочинения музыки (2026-10-27):** на маке работает через MLX
  (при ≤6 ГБ — модель 2B turbo без планировщика); русский в списке
  языков текстов (качество не проверено); кавер, перерисовка фрагмента,
  Vocal2BGM (аранжировка под готовый вокал), LoRA по ~8 песням. Веса — HF
  и ModelScope. Навык транскрипции текста из репозитория отправляет аудио
  в OpenAI/ElevenLabs — не ставить.

## Риски и оговорки

- Код MIT; **лицензия весов не проверена** (карточка на Hugging Face не
  открылась).
- Режим «≤4 ГБ» — заявление авторов; скорость в нём и поведение INT8 на
  Pascal неизвестны.
- Требует PyTorch (≤2.14 cu126).
- Альтернативы с некоммерческими весами (MusicGen, YuE) не подходят для
  монетизации.

Пункт 6 плана в исследовании: один трек на 30 с в режиме «≤4 ГБ».
