# Producer Pal

- **Ссылка:** https://github.com/adamjmurray/producer-pal
- **Что это:** MCP-сервер для Ableton Live в виде устройства Max for Live — Claude управляет сетом: дорожки, клипы, MIDI, аранжировка, громкость/пан/посылы, запись
- **Найдено:** 2026-10-27, исследование музыки и звука
- **Статус:** попробовать первым — у владельца Live 12.4.7 Suite (2026-10-27), требование 12.3+ выполнено

## Зачем фабрике

Помощь в сочинении и подготовке сессий: дорожки, клипы и MIDI, сцены,
аранжировка (перемещение, нарезка, локаторы, take lanes), микс (громкость,
пан, посылы, маршрутизация, arm). Самый зрелый сервер для Ableton (~7 300
коммитов, последний 2026-10-01). Есть отдельная инструкция для Claude Code
и сужение набора инструментов (`--tools core,clip,track`). Где запускать —
на маке, рядом с Live.

## Риски и оговорки

- GPL-3, 349 ★. Телеметрии в коде не найдено.
- **HTTP-сервер без авторизации слушает все сетевые интерфейсы** — закрыть
  входящие к Max в брандмауэре macOS.
- Нет: правки автоматизации и огибающих клипов, анализа звука, доступа к
  параметрам плагинов вне списка Configure (до 128). Экспорт и сохранение
  сета Live API не умеет.
- Нужна редакция Suite (или Max for Live) и Node 20+. Версию `npx`-пакета
  закреплять.

## Как подключить

```
# Live 12.3+ с Max for Live; Producer_Pal.amxd из релизов — на MIDI-дорожку
claude mcp add producer-pal -- npx producer-pal@<версия> --tools core,clip,track
```
Подробно — навык `ableton-control` пакета `audio/packs/music-studio`.
