# Phantom

- **Ссылка:** https://github.com/fadelabs/phantom
- **Что это:** CLI + MCP (20 инструментов) + 5 навыков для анализа микса: маскировка частот между стемами, фаза, сравнение с референсом, 9 жанровых профилей
- **Найдено:** 2026-10-27, подборка навыков для музыки
- **Статус:** попробовать — только CLI, без его навыков

## Зачем фабрике

Новое по сравнению со скриптами пакета `music-studio`: **маскировка «голос
против минусовки»** — где именно вокал и бит спорят за одни частоты.
Остальное частично дублирует `audio-measure`, `mix-review` и Matchering.

## Риски и оговорки

- AGPL-3, ~40 ★, активен (2026-10-04). Только macOS и Linux.
- Анализ локальный. Статистика собирается только в curl-установщике —
  ставить через uv, а если нужно, `PHANTOM_NO_TELEMETRY=1`.
- **Не запускать `phantom setup-ableton`** — он ставит Remote Script от
  ahujasid (с телеметрией по умолчанию); для Ableton у владельца Producer Pal.

## Как подключить

```
uv tool install phantom-audio
```
Первый тест — маскировка вокала и минусовки на одном миксе, сравнить с
`mix_compare.py`.
