# ruaccent + RussianPoetryScansionTool

- **Ссылки:** https://github.com/Den4ikAI/ruaccent · https://github.com/RussianNLP/RussianPoetryScansionTool
- **Что это:** библиотеки для русского текста: ruaccent расставляет ударения (есть модель для стихов `big_poetry`, ONNX без PyTorch); RPST определяет размер (включая дольник), рифмы (в том числе неточные) и оценивает технику стиха
- **Найдено:** 2026-10-27, подборка навыков для музыки
- **Статус:** попробовать — основа своего навыка `lyrics-ru`

## Зачем фабрике

- Текст песни для студии с расставленными ударениями (навык
  `vocal-recording` уже советует это делать — ruaccent делает автоматически).
- Проверка ритма: ударные слоги на сильных долях сетки (связь с
  `vocal-over-beat` и сеткой долей фабрики), размер и рифмы при сочинении.
- Готового навыка Claude для русских текстов песен нет — его придётся
  написать поверх этих библиотек.

## Риски и оговорки

- Обе — MIT. ruaccent ~220 ★, активен (2026-07); RPST ~14 ★, 2025 (форк
  Koziev — 2025-07); песенная лирика заявлена прямо.
- ruaccent — ONNX, лёгкий; модели скачиваются с Hugging Face (с сервера
  может быть недоступно — качать через мак).
- RPST тяжелее: нужен torch (CPU или MPS на маке).

## Как подключить

`pip install ruaccent`; RPST — `pip install .` из клона. Затем — свой навык
`lyrics-ru` в пакете `audio/packs/music-studio`.
