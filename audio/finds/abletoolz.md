# abletoolz

- **Ссылка:** https://github.com/elixirbeats/abletoolz
- **Что это:** CLI и Python-библиотека для файлов сетов Ableton (.als), поддерживает Live 12
- **Найдено:** 2026-10-27, подборка навыков для музыки
- **Статус:** попробовать

## Зачем фабрике

- Проверка сетов, которые приходят со студии после «Collect All and Save»:
  пропавшие сэмплы и плагины, починка путей по базе сэмплов, отчёт в JSON и
  сводка `.meta.yaml`.
- Дополняет Producer Pal: тот работает с открытым Live, abletoolz — с
  файлами без запуска Live. Через Python можно писать MIDI и переносить
  цепочки устройств.
- Поддержка VST3 и AU в сетах macOS.

## Риски и оговорки

- GPL-3, ~130 ★, активен (2026-08).
- Перед записью делает резервную копию оригинала.
