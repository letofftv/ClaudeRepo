# Matchering 2.0

- **Ссылка:** https://github.com/sergree/matchering
- **Что это:** мастеринг по референсу — подгоняет громкость, АЧХ, пики и ширину стерео трека под выбранный референс
- **Найдено:** 2026-10-27, исследование открытых инструментов
- **Статус:** попробовать

## Зачем фабрике

- Быстрый черновой мастер или ориентир «как звучал бы мой трек в подаче
  референса» — для сравнения со своим мастером в Ableton.
- Python API в одну строку, CLI и Docker-приложение; на CPU, на маке
  работает. Стабилен (v2.0.6), встроен в UVR.

## Риски и оговорки

- GPL-3 — для использования ок, ограничения только при распространении кода.
- Результат зависит от референса: брать трек того же жанра и подачи вокала.
- Не заменяет решения мастеринга: проверять `loudness_report.py --role
  master` и слухом. Для пережатых минусовок может дожать лишнее.

## Как подключить

```python
import matchering as mg
mg.process(target="mix.wav", reference="reference.wav",
           results=[mg.pcm24("master_24bit.wav")])
```
