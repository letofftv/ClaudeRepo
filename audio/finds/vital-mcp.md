# vital-mcp

- **Ссылка:** https://github.com/mard4/vital-mcp
- **Что это:** MCP-сервер для создания и правки пресетов бесплатного синтезатора Vital (~800 параметров, модуляции, волновые таблицы) с прослушиванием пресета через DawDreamer
- **Найдено:** 2026-10-27, подборка навыков для музыки
- **Статус:** попробовать

## Зачем фабрике

Дизайн звука словами: Claude собирает и правит пресеты Vital,
`render_preset` проигрывает пресет и делает замеры. Бесплатная замена
serum-mcp (Serum 2 платный и из России не купить).

## Риски и оговорки

- GPL-3, ~2 ★, очень молодой проект (2026-10-12).
- Сеть не используется; перед перезаписью пресета делает копию.
- Ставится из ветки main — **закрепить на конкретном коммите**.
- Нужен Vital 1.5+ с VST3.

## Как подключить

```
claude mcp add -s user vital -- uvx --from "git+https://github.com/mard4/vital-mcp@<коммит>" vital-mcp
```
(точную команду сверить с README).
