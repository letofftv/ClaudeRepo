# 1c-odata-mcp

- **Ссылка:** https://github.com/evilbruce666/1c-odata-mcp (для программиста 1С — также https://github.com/vladimir-kharin/1c_mcp, MCP внутри расширения 1С)
- **Что это:** MCP-сервер для вопросов к базе 1С обычным языком через OData
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** попробовать — если у бизнеса 1С с опубликованным OData

## Зачем фабрике

Отчёты и ответы из учёта 1С («сколько отгрузили за месяц», «долги
контрагентов») без выгрузок в Excel.

## Риски и оговорки

- MIT, ~35 ★, npm 0.12.0 (2026-10-26).
- По умолчанию **только чтение**; запись требует двух переключателей и
  dry-run с operationId; удаления нет — только пометка; пароль не попадает
  в логи.
- Работает локально; нужен опубликованный OData-интерфейс базы.

## Как подключить

По README (npm); начинать с режима чтения.
