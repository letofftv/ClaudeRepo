# Официальные MCP Bitrix24

- **Ссылки:** `io.github.bitrix24/bitrix-mcp-rest` (документация REST, mcp-dev.bitrix24.com/mcp) · `io.github.bitrix24/bitrix24` (данные портала, mcp.bitrix24.com/mcp/) — в официальном MCP Registry
- **Что это:** два удалённых MCP-сервера Bitrix24: справка по REST API и доступ к данным портала (CRM, задачи)
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** docs-MCP — взять; data-MCP — попробовать на своём портале

## Зачем фабрике

- Bitrix24 — самая доступная CRM для малого бизнеса в России (бесплатный
  тариф, вебхуки).
- Docs-MCP: Claude Code пишет интеграции с Bitrix24, не выдумывая методы.
- Data-MCP: вопросы к CRM и задачам обычным языком.

## Риски и оговорки

- Источник официальный (namespace подтверждён организацией Bitrix24 на GitHub).
- Работает ли data-MCP с порталами на .ru — неясно (есть сообщения, что
  OAuth-эндпоинты отдают 404). Запасной путь — входящий вебхук + n8n.
- Данные CRM уходят в Anthropic — **персональные данные клиентов —
  трансграничная передача по 152-ФЗ**: минимизировать или обезличивать.
- Официальный MCP в самом Битрикс24 требует платного тарифа и подписок
  (см. `productivity/`) — здесь речь о серверах из Registry.

## Как подключить

Docs-MCP — по адресу из Registry в Claude Code; data-MCP — сначала проверить
вход на своём портале, токены только на чтение.
