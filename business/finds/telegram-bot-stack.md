# Бот на aiogram + ЮKassa SDK

- **Ссылки:** https://github.com/aiogram/aiogram · ЮKassa SDK `yookassa` (PyPI; код переехал на git.yoomoney.ru)
- **Что это:** стек клиентского Telegram-бота: aiogram 3 (Bot API 10.3) + официальный Python SDK ЮKassa (платежи, чеки по 54-ФЗ, СБП)
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** взять

## Зачем фабрике

Бот для клиентов: заявки, запись, оплата через ЮKassa, уведомления из n8n.
Claude Code пишет бота (свежая документация aiogram — через Context7),
события бот передаёт в n8n.

## Риски и оговорки

- Обе библиотеки — MIT; aiogram ~5,9 тыс. ★, 3.31.0 (2026-08-26); yookassa
  3.13.0 (2026-10-06), GitHub-репозиторий в архиве — код на git.yoomoney.ru.
- **Ключи ЮKassa остаются в коде бота или в n8n** — Claude их не видит;
  в репозиторий не записывать.
- Это не MCP, а библиотеки — постоянного веса в контексте нет.

## Как подключить

`pip install aiogram yookassa`; Claude Code — с навыком superpowers и
Context7 (`coding/`).
