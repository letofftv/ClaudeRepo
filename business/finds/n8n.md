# n8n (свой сервер) + встроенный MCP

- **Ссылка:** https://github.com/n8n-io/n8n
- **Что это:** платформа автоматизации процессов; с версии 2.2 — встроенный MCP-сервер на уровне инстанса, с ~2.13–2.14 Claude может сам собирать воркфлоу
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** взять — хребет автоматизации

## Зачем фабрике

- Все интеграции бизнеса в одном месте: вебхуки Tilda, ЮKassa и Bitrix24,
  отчёты, связки с ботами, уведомления в Telegram.
- Claude проектирует и запускает воркфлоу, а **ключи хранятся в n8n, а не в
  чате** — модель их не видит.
- Ставится на домашний сервер в Docker; использует уже работающие Postgres
  и Redis. Есть community-ноды Bitrix24 и amoCRM.

## Риски и оговорки

- ~209 тыс. ★. Лицензия **Sustainable Use License**: внутри своей компании
  бесплатно, перепродавать как сервис нельзя (если начнётся работа на
  клиентов — посмотреть Activepieces, MIT).
- **n8n Cloud из России не оплатить** (Paddle отклоняет) — только свой сервер.
- MCP выключен по умолчанию, включается для каждого воркфлоу отдельно, вход
  через OAuth. Наружу n8n не выставлять — подключаться с мака по WireGuard.
- Запись в чужие системы — через воркфлоу с подтверждением владельца в Telegram.

## Как подключить

Docker на сервере → включить MCP в настройках инстанса и для нужных
воркфлоу → в Claude Code `/mcp` → Authenticate. Навыки — `n8n-skills.md`.
