# marketplaces-mcp-ru

- **Ссылка:** https://github.com/ilyautov/marketplaces-mcp-ru
- **Что это:** MCP-сервер для маркетплейсов: Wildberries, Ozon (Seller и Performance), Яндекс Маркет, Авито — 1 022 метода через ~30 общих инструментов
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** попробовать — если бизнес торгует на маркетплейсах

## Зачем фабрике

Остатки, заказы, цены, отчёты и реклама на главных российских площадках —
из одного сервера, без отдельной интеграции под каждую.

## Риски и оговорки

- MIT, ~56 ★, активен (2026-10-07), PyPI 0.6.1.
- Методы помечены read / write / destructive; запись требует флагов, есть
  тест в CI. Сеть — только на хосты площадок; телеметрии нет.
- **HTTP-режим без авторизации — использовать только stdio** (локально в
  Claude Code на маке).
- Начинать с токенов только на чтение.

## Как подключить

```
uvx marketplaces-mcp-ru
```
или `python3 install.py --client claude-code` (сверить с README).
