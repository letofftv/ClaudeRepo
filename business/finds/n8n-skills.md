# n8n-io/skills (официальный плагин)

- **Ссылка:** https://github.com/n8n-io/skills
- **Что это:** официальный плагин n8n для Claude Code — 15 навыков: выражения, Code-ноды, обработка ошибок, креды, Data Tables; MCP указывает только на ваш инстанс
- **Найдено:** 2026-10-27, подборка для цифровизации бизнеса
- **Статус:** взять (вместе с n8n)

## Зачем фабрике

Claude правильно собирает воркфлоу n8n с первого раза: синтаксис
выражений, Code-ноды, обработка ошибок, работа с кредами — без выдуманных
нод и параметров.

## Риски и оговорки

- Apache-2.0, ~560 ★, активен (2026-10-17).
- Хуки прочитаны: SessionStart вставляет мета-навык, PreToolUse добавляет
  напоминания; сетевых вызовов нет. Вес средний.
- Альтернатива czlonkowski/n8n-mcp (23 тыс. ★) — **телеметрия по умолчанию
  отправляет структуры воркфлоу автору**; брать только если официального
  не хватит, с `N8N_MCP_TELEMETRY_DISABLED=true`. Плагин czlonkowski/n8n-skills
  по умолчанию подключён к хостингу автора — не ставить как есть.

## Как подключить

```
/plugin marketplace add n8n-io/skills
/plugin install n8n-skills@n8n-io
```
затем указать URL своего инстанса → `/mcp` → Authenticate. Перед установкой — SkillSpector.
