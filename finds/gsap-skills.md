# gsap-skills

- **Ссылка:** https://github.com/greensock/gsap-skills
- **Что это:** официальные навыки GSAP для агентов от GreenSock
- **Найдено:** 2026-10-26, из awesome-motion-design-agent-skills
- **Статус:** попробовать (вместе с HyperFrames)

## Зачем фабрике

HyperFrames анимирует сцены через GSAP. Эти навыки дают агенту точное знание
API: таймлайны, плавности, stagger, плагины для кинетической типографики
(SplitText, ScrambleText, MorphSVG), утилиты и производительность. Меньше
ошибок и «самодельной» анимации там, где у GSAP есть готовый инструмент.

## Риски и оговорки

- MIT, официальный источник (GreenSock), ~15,8 тыс. ★ (по данным подборки на
  2026-09-28).
- Только Markdown: 8 навыков, без хуков, скриптов и сетевых вызовов. Плагин
  для Claude Code есть.
- Часть навыков про сайты, а не видео: `gsap-react`, `gsap-frameworks`
  (Vue/Svelte), `gsap-scrolltrigger`. Их ставить не нужно.
- Навыки сами подтверждают: GSAP с 2025 года полностью бесплатен, включая все
  плагины и коммерческое использование.
- Имеет смысл, только если выбран HyperFrames.

## Как подключить

Вместе с HyperFrames, только нужные для видео навыки:

```
npx skills add greensock/gsap-skills --skill gsap-core --skill gsap-timeline \
  --skill gsap-plugins --skill gsap-utils --skill gsap-performance -a claude-code
```

(Флаг `--skill` описан в README подборки; если CLI примет только один навык
за раз — повторить команду для каждого.)
