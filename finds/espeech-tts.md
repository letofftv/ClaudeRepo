# ESpeech-TTS-1

- **Ссылка:** https://huggingface.co/ESpeech/ESpeech-TTS-1_SFT-256K (база — https://github.com/SWivid/F5-TTS)
- **Что это:** русская доработка F5-TTS: качественная озвучка с клонированием голоса
- **Найдено:** 2026-10-26, исследование локальной озвучки
- **Статус:** попробовать (если omnivoice.cpp не устроит по качеству)

## Зачем фабрике

- В сравнении на Habr и по отзывам — «отличное» качество русского, советуют
  вместе с Silero как базовый выбор.
- Клонирование голоса по образцу.
- ~336M параметров — должна влезть в 4 ГБ в FP32 (не проверено). Медленнее
  реального времени — для пакетной озвучки роликов это нормально.

## Риски и оговорки

- **Лицензия:** вариант SFT-256K отмечен как Apache-2.0 — но только по
  поисковой выдаче, страница модели не открылась. У базовых весов F5-TTS и у
  других русских доработок — CC-BY-NC. Проверить до использования.
- Требует PyTorch: README F5-TTS ставит torch 2.8 cu128 — на этой карте не
  пойдёт, нужна сборка cu126 (≤2.14). Платформа «заморожена».
- Скорость на 1050 Ti неизвестна (единственный замер — 3–5 с на фразу на 4090).
- OpenAI-совместимый сервер — только любительский (`f5-tts-api`).

## Как подключить

Пока нет. Сначала проверить лицензию на Hugging Face и результаты A/B
omnivoice.cpp / qwentts.cpp / Silero.
