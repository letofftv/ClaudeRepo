# awesome-motion-design-agent-skills

- **Ссылка:** https://github.com/frankxai/awesome-motion-design-agent-skills
- **Что это:** подборка ресурсов по моушн-дизайну для агентов + 5 собственных навыков автора (плагин `motion-design-studio`)
- **Найдено:** 2026-10-26, сначала попалась в подборке по анимации, затем владелец прислал ссылку
- **Статус:** навыки — отклонено; подборка — источник следующих находок

## Зачем фабрике

**Собственные навыки — почти ни зачем.** Это короткие чек-листы и шаблоны
промптов (29–116 строк), а не рабочие инструкции:

- `remotion-video-agent` — общий чек-лист на 33 строки; официальные навыки
  Remotion и навыки HyperFrames намного подробнее.
- `generative-media-director` — шаблоны промптов и маршрутизация только по
  **облачным** платным сервисам (Sora, Veo, Grok, Luma, Runway, Higgsfield).
  Локальные модели на видеокарте не упоминаются.
- `motion-director` — выбор библиотеки анимации, общие советы.
- `site-motion-excellence-director`, `web-motion-auditor` — про анимацию на
  сайтах; первый вообще заточен под сайты самого автора (FrankX, Arcanea,
  Starlight).

**Подборка — полезна как список ссылок.** Самое интересное для фабрики
(не проверено, кандидаты на отдельные карточки):

- `greensock/gsap-skills` — официальные навыки GSAP для агентов. HyperFrames
  анимирует через GSAP, так что это прямое дополнение к первому кандидату.
- `AbubakrChan/product-launch-motion` — навык Claude Code: ссылка на сайт →
  ролик 60 fps с музыкой и эффектами, через Playwright и FFmpeg. Близко к
  обучающим видео по интерфейсам.
- `Orkas-AI/Orkas-VideoStudio` — набор из 14 навыков для видео по плану
  `plan.json`.
- `NVIDIA/SkillSpector` — сканер наборов навыков перед установкой. Может
  пригодиться самой песочнице для проверки находок.

## Риски и оговорки

- Лицензия CC0 (общественное достояние). Плагин — только 5 навыков в
  Markdown: без хуков, MCP-серверов и скриптов. Безопасен, но малоценен.
- Автор ведёт «флот» из десятков однотипных awesome-списков (в т.ч. про
  «манифестацию» и «агентский доход»); правки идут по шаблону «Fleet
  standard». Глубина отбора ограничена: в подборке по видео нет даже
  HyperFrames (~72,9 тыс. ★).
- Звёзды в подборке сняты 2026-09-28 — уже немного устарели.
