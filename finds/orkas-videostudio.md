# Orkas-VideoStudio

- **Ссылка:** https://github.com/Orkas-AI/Orkas-VideoStudio
- **Что это:** конвейер видео для агентов поверх HyperFrames, FFmpeg и whisper.cpp: композиция, монтаж, генерация, авто-сборка по `plan.json`
- **Найдено:** 2026-10-26, из awesome-motion-design-agent-skills
- **Статус:** попробовать (вторым, после HyperFrames)

## Зачем фабрике

Закрывает то, чего нет в самом HyperFrames, — **монтаж реальных записей**:

- `trim-silence`, `remove-fillers` — вырезать паузы и «эээ» из записи;
- `transcribe` — локальная расшифровка через whisper.cpp, `burnsubs` —
  вшить субтитры, `loudness` — выровнять громкость;
- `scenes`, `quality`, `rank-takes` — найти лучшие куски в длинной записи
  экрана и нарезать клипы;
- `speak`, `mix`, дубляж и локализация озвучки.

Видео описывается редактируемым `plan.json`: правка одной строки
перерендеривает только этот кусок. Есть CLI `ovs`, MCP-сервер и 14 навыков.

**Озвучка на своей видеокарте (гипотеза, не проверено):** TTS подключается к
любому OpenAI-совместимому адресу (`OVS_TTS_BASE_URL`). Если поднять на
сервере локальную TTS-модель с таким API, озвучка будет бесплатной и без облака.

## Риски и оговорки

- MIT, 328 ★, **ранняя разработка**: npm-пакеты ещё не опубликованы,
  установка из исходников (`pnpm install && pnpm build`).
- Закреплён на HyperFrames 0.7.60, а актуальный — 0.8.205: возможны
  расхождения с плагином HyperFrames.
- Генерация картинок, видео и озвучки — через свои ключи облачных
  провайдеров (OpenAI, Gemini, Doubao и др.). Монтаж и композиция работают
  без ключей.
- Телеметрии нет; в коде только адреса провайдеров, которые используются при
  заданных ключах; скриптов при установке нет.

## Как подключить

После того как HyperFrames опробован:

```
git clone https://github.com/Orkas-AI/Orkas-VideoStudio.git
cd Orkas-VideoStudio && pnpm install && pnpm build
node packages/cli/dist/index.js doctor
node packages/cli/dist/index.js skills --install --target claude
```

Первая проба: взять запись экрана, вырезать паузы, вшить субтитры.
