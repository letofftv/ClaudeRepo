# LiveBridge

- **Ссылка:** https://github.com/valentijnh/livebridge-ableton-mcp
- **Что это:** MCP-сервер для Ableton Live 12 (любая редакция) с упором на сведение и мастеринг — микс в дБ, автоматизация, замер LUFS и спектра против референса
- **Найдено:** 2026-10-27, исследование музыки и звука
- **Статус:** попробовать осторожно

## Зачем фабрике

- Микс в децибелах, шины, сайдчейн, метры.
- Автоматизация: в клипах и записью в реальном времени в аранжировку.
- Замер баунса: LUFS, спектр, стерео, тональность — в том числе против
  референса.
- Параметры VST3-плагинов без ручного Configure (до 128).
- Работает без Max for Live — подходит для Live Standard.

## Риски и оговорки

- MIT, **11 ★, один разработчик** — молодой проект.
- **Инструмент произвольного Python внутри Live (`live_eval_python`)
  включён по умолчанию** — запускать с `--no-allow-eval`.
- Установщик добавляет Splice MCP (отключить `--no-splice`) и пишет навык в
  `~/.claude/skills/livebridge` — прогнать через SkillSpector.
- Слушает localhost с токеном. 168 инструментов — сужать набор.
- Live 11 не поддерживается.

## Как подключить

Склонировать, прочитать `installers/install.sh`, запустить с
`--no-allow-eval --no-splice`; в Live выбрать LiveBridge в Control Surface,
попросить Claude вызвать `live_status`.
