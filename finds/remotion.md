# Remotion

- **Ссылка:** https://github.com/remotion-dev/remotion
- **Что это:** видео пишется кодом на React и рендерится в MP4
- **Найдено:** 2026-10-26, подборка по анимации на GitHub
- **Статус:** позже (запасной вариант к HyperFrames)

## Зачем фабрике

Те же задачи, что у HyperFrames: анимация, клипы, обучающие ролики. Самая
зрелая экосистема: много шаблонов, официальные навыки для агентов
(`remotion-dev/skills`), сотни сторонних навыков и примеров с Claude Code.

## Риски и оговорки

- **Лицензия особая:** в ряде случаев компании нужна платная лицензия. Перед
  выбором прочитать LICENSE и сверить с тем, монетизируются ли ролики.
- Пересекается с HyperFrames — держать только один. Если HyperFrames не
  подойдёт, переходить сюда.
- ~67,8 тыс. ★.

## Как подключить

Только если HyperFrames отклонён: `npx create-video@latest`, навыки —
`npx skills add remotion-dev/skills`.

## Что проверено

Только страница репозитория и сторонние гайды. Код не смотрелся.
