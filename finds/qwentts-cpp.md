# qwentts.cpp

- **Ссылка:** https://github.com/ServeurpersoCom/qwentts.cpp
- **Что это:** C++/GGML-порт Qwen3-TTS с OpenAI-совместимым сервером озвучки и клонированием голоса
- **Найдено:** 2026-10-26, исследование локальной озвучки
- **Статус:** попробовать (в паре с omnivoice.cpp)

## Зачем фабрике

- **Pascal поддержан официально:** образ `:cuda12` собран для архитектур от
  Pascal (sm_61) до Blackwell; `:cuda13` — только от Turing. Есть образы
  `:cpu` и `:vulkan`, скрипт сборки под Windows.
- **Лицензии чистые:** код MIT, веса Qwen3-TTS — Apache-2.0, коммерция
  разрешена.
- **Сервер для Orkas готов:** `/v1/audio/speech`, `/v1/audio/voices`
  (клонированные голоса), `/v1/models`, `/health`; флаг `--lang`.
- Модели 0.6B и 1.7B в GGUF (Q8_0, Q4_K_M) — 0.6B-Q8 или 1.7B-Q4 должны влезть
  в 4 ГБ (вывод, замеров нет).

## Риски и оговорки

- **Русский слабее**, чем у Silero и ESpeech (по отзывам), и готовых русских
  голосов нет — нужен Base-режим и клон русского голоса, на который есть права.
- Вывод только `wav`/`pcm` — mp3 возвращает ошибку; в Orkas
  `OVS_TTS_FORMAT=wav`. Язык задавать флагом `--lang` при запуске.
- Скорость на Pascal неизвестна; при длинных абзацах можно упереться в
  таймаут Orkas (60 с).
- Молодой проект одного автора (~200 ★, последний коммит 2026-10-16).

## Как подключить

```
docker run ... ghcr.io/serveurpersocom/qwentts.cpp:cuda12   # параметры — по README
```

Настройки Orkas — в разделе 2 исследования.
