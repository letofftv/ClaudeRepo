# SkillSpector

- **Ссылка:** https://github.com/NVIDIA/SkillSpector
- **Что это:** сканер безопасности для навыков агентов от NVIDIA — проверяет навык до установки
- **Найдено:** 2026-10-26, из awesome-motion-design-agent-skills
- **Статус:** взять (для проверки находок перед установкой на фабрику)

## Зачем фабрике

Это инструмент для самой песочницы: перед установкой любого навыка или
плагина прогонять его через сканер. Ищет 71 шаблон уязвимостей в 17
категориях: внедрение промптов, утечка данных, повышение привилегий, атаки
через зависимости и др. Отчёт с оценкой риска 0–100.

По их исследованию, в 26% навыков есть уязвимости, а у 5% — признаки
вредоносности. Это подтверждает правило «читать до установки».

Два режима:
- статический анализ — быстро, без ключей (`--no-llm`);
- плюс проверка смысла через LLM — в том числе **локальной моделью через
  Ollama** или OpenAI-совместимый адрес, то есть на видеокарте сервера.

## Риски и оговорки

- Apache-2.0, NVIDIA, ~18,5 тыс. ★ (по данным подборки). Часть конвейера
  NVIDIA Verified Skills.
- Сканер не заменяет чтение кода: он ловит известные шаблоны.
- Проверка CVE ходит в OSV.dev (при отсутствии сети есть офлайн-режим).
- В этой облачной песочнице запускать его не дала защита сессии (запуск
  скачанного кода). Чтобы сканировать здесь, владельцу нужно разрешить это
  в настройках; иначе — запускать на сервере.

## Как подключить

На сервере, в Docker (Python ставить не нужно):

```
git clone https://github.com/NVIDIA/skillspector.git && cd skillspector
docker build -t skillspector .
docker run --rm -v "$PWD:/scan" skillspector scan ./путь-к-навыку/ --no-llm
```

Правило для фабрики: каждый навык из `finds/` со статусом «взять» или
«попробовать» — сначала через сканер.
