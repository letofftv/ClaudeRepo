- **Найдено:** 2026-10-26, из awesome-motion-design-agent-skills
- **Статус:** попробовать

## Зачем фабрике

- **Промо-клипы и UI-ролики.** v2 (октябрь 2026) — сильная режиссура в
  навыке: «одна фигура без склеек» (кнопка превращается в лоадер, график,
  палитру команд…), пружинная анимация, курсор, который делает все клики,
  камера, монтаж под бит музыки. Бит измеряется через numpy, звуки
  синтезируются и ставятся точно на долю.
- **Всё локально и бесплатно:** Playwright снимает по 4 подкадра на кадр,
  FFmpeg склеивает их в motion blur. Никаких ИИ-видеомоделей и платных API.
- **Для обучающих видео — версия v1** (лежит в `legacy/`): ролики под
  озвучку на HyperFrames + GSAP, кадры синхронизированы со словами диктора.
  Сам автор пишет, что для объясняющих роликов с голосом v1 лучше.
- Детерминированный рендер: любой кадр воспроизводим, можно рендерить
  параллельно.

## Риски и оговорки

- MIT на навык и справочники. Примеры роликов из репозитория чужие (сделаны
  для Cheerful) — их нельзя переиспользовать; см. `NOTICE`.
- Интерфейс воссоздаётся в HTML, а не снимается с экрана — стилизация, не
  запись настоящей платформы. Для точных туториалов нужен Playwright MCP.
- Автор советует Opus 5.5: на меньших моделях результат слабее.
- Музыку нужна своя, с проверенной лицензией.
- Небольшой проект (~250 ★ по данным подборки), один автор; в README есть
  ссылка на его платный сервис.

## Как подключить

```
npx skills add AbubakrChan/product-launch-motion          # v2 — промо
npx skills add AbubakrChan/product-launch-motion/legacy   # v1 — под озвучку
```

Нужны Node 20+, Playwright, FFmpeg, Python 3 + numpy.
