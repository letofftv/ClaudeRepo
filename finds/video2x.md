# Video2X

- **Ссылка:** https://github.com/k4yt3x/video2x
- **Что это:** CLI для апскейла и интерполяции кадров видео на Vulkan (Real-ESRGAN, Real-CUGAN, RIFE внутри)
- **Найдено:** 2026-10-26, исследование вспомогательных инструментов
- **Статус:** попробовать

## Зачем фабрике

- **Работает на этой карте:** Vulkan/ncnn без CUDA и PyTorch, тайлинг
  ограничивает память. Нужна видеокарта с Vulkan и процессор с AVX2.
- Апскейл анимации и старых материалов (`realesr-animevideov3` — быстрая
  модель для анимации), RIFE — плавность и замедление (сглаживает петли
  AnimateDiff).
- Чистый CLI и Docker-образы — подходит для конвейера.

## Риски и оговорки

- AGPL-3 — для внутреннего использования на своём сервере нормально;
  выходные видео лицензией не ограничены [память].
- Записи экрана апскейлить незачем — их лучше сразу снимать в нужном
  разрешении.
- Для отдельных картинок проще `realesrgan-ncnn-vulkan` (MIT).

## Как подключить

```
video2x -i in.mp4 -o out.mp4 -p realesrgan -s 4 --realesrgan-model realesr-animevideov3
```
