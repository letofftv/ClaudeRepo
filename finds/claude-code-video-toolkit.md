## Зачем фабрике

Здесь самые близкие к обучающим видео ссылки — их стоит разобрать отдельными
карточками:

- **digitalsamba Claude Code Video Toolkit** — шаблон проекта с командой
  `/record-demo` (запись экрана через Playwright) и навыками Remotion,
  FFmpeg, ElevenLabs.
- **Playwright MCP с флагом `--save-video`** — агент сам проходит сценарий в
  браузере и записывает видео. Основа для автоматических роликов по
  интерфейсам веб-платформ.
- **YouTube Clipper Skill** — нарезка, главы, перевод и вшивание субтитров.
