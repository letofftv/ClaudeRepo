# mesh-avatar-studio

- **Ссылка:** https://github.com/shinshin86/mesh-avatar-studio (рантайм — npm `mesh-avatar`)
- **Что это:** одна иллюстрация → 2D-меш-аватар, который моргает, говорит по громкости голоса, поворачивает голову и дышит; с гайдом для агента
- **Найдено:** 2026-10-27, подборка лучших навыков для анимации
- **Статус:** попробовать (оживляет живописного персонажа без видео-драйвера)

## Зачем фабрике

- Живописный портрет (например, стилизованный по схеме «живописный 2.5D»)
  оживает без видеомодели: моргание, рот по громкости (русский голос
  подходит), поворот головы, дыхание.
- В рантайме есть `manual: true` + `advance()` «для офлайн-рендера видео» —
  встраивается в покадровый рендер фермы.
- В паре с LivePortrait (мимика по видео на маке).

## Риски и оговорки

- MIT (кроме образца персонажа), ~1,2 тыс. ★, активен (2026-10-27).
- Всё локально; Node 22.17+, uv, Playwright.
- **Путь через Codex отправляет картинки в OpenAI и запускается с
  `--approve-for-me` — не использовать**; работать через Claude по
  `docs/agent-guide.md`.

## Как подключить

`npx create-mesh-avatar-studio`, затем Claude по `docs/agent-guide.md`.
