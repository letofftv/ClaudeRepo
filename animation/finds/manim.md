# Manim

- **Ссылка:** https://github.com/3b1b/manim и версия сообщества https://github.com/ManimCommunity/manim
- **Что это:** движок объясняющих анимаций на Python (на нём сделаны ролики 3Blue1Brown)
- **Найдено:** 2026-10-26, подборка по анимации на GitHub
- **Статус:** позже

## Зачем фабрике

Для обучающих видео — вставки, где нужно объяснить идею: схемы, формулы,
алгоритмы, анимированные диаграммы. Интерфейсы платформ им не показать, это
дополнение к основному инструменту, а не замена.

## Риски и оговорки

- Для работы с агентом брать версию сообщества (ManimCommunity): она лучше
  документирована, под неё есть сторонние навыки и MCP-серверы (не проверены).
- Готовые рендеры Manim можно встраивать в HyperFrames — навык
  `remotion-to-hyperframes` это поддерживает.
- ~95,7 тыс. ★ (3b1b), ~41,9 тыс. ★ (сообщество).

## Как подключить

Когда понадобятся объясняющие вставки: `pip install manim` (для формул нужен
LaTeX).

## Что проверено

Только страницы репозиториев.
