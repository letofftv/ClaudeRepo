# ClaudeAnimationBase

- **Ссылка:** https://github.com/JohnHeibel/ClaudeAnimationBase
- **Что это:** набор для «живописной» анимации кодом с руководством для агента (ANIMATION_GUIDE): p5.js + p5.brush в headless Chrome → MP4
- **Найдено:** 2026-10-27, подборка лучших навыков для анимации
- **Статус:** попробовать (лучший «живописный» язык кодом)

## Зачем фабрике

- Та же архитектура, что у фермы (кадр как функция времени, браузер, ffmpeg) —
  встраивается как источник приёмов и блоков.
- p5.brush: акварель, мазки, «кипящая» линия — вид иллюстрированной книжки,
  ближе к референсам «Города пробок», чем векторная графика.
- Персонаж с 31 эмоцией; процесс раскадровка → контактные листы → MP4.
- Потолок «узнаваемое лицо» не снимает — для этого схема «живописный 2.5D».

## Риски и оговорки

- MIT, ~2,1 тыс. ★, активен (2026-09-24). Хуков нет, сеть только для npm.
- Не плагин — клон и `npm install`.
- Акварельным заливкам нужна видеокарта (WebGL) — проверить на маке, где
  рендер быстрее всего.
- Персонаж-образец Clawd — маскот Anthropic; заменить своим.

## Как подключить

`git clone` + `npm install`; читать ANIMATION_GUIDE и переносить приёмы на ферму.
