# paint-mv-skills

- **Ссылка:** https://github.com/lintsinghua/paint-mv-skills
- **Что это:** 4 навыка: песня + текст → акварельный клип (сетка долей, выравнивание текста, кадр на строку, параллельные субагенты рисуют главы)
- **Найдено:** 2026-10-27, подборка лучших навыков для анимации
- **Статус:** попробовать — на 20–30 с «Города пробок»

## Зачем фабрике

Ровно задача текущего клипа: живописные сцены под музыку и текст. У
фабрики уже есть сетка долей и сверенная разметка вокала — их можно подать
на вход вместо собственного анализа навыка.

## Риски и оговорки

- MIT, но движок подтягивается из PDoomVideo, у которого нет файла LICENSE
  (в package.json — ISC); проект молодой (~46 ★).
- `new_project.mjs` клонирует PDoomVideo на закреплённом коммите — читать
  перед запуском.
- Часть текста навыков на китайском. Есть патч под macOS.

## Как подключить

Скопировать `skills/` в `~/.claude/skills` после SkillSpector; первый тест —
короткий фрагмент клипа.
