# Comfy MCP (официальный)

- **Ссылка:** https://github.com/Comfy-Org/comfy-mcp
- **Что это:** официальный MCP-сервер ComfyUI (бета, 40 инструментов): Claude запускает и проверяет воркфлоу, делает пакеты вариантов
- **Найдено:** 2026-10-27, подборка лучших навыков для анимации
- **Статус:** попробовать — когда соберётся воркфлоу «живописного 2.5D»

## Зачем фабрике

Через `COMFYUI_URL` Claude на маке управляет ComfyUI на сервере (сборка
cu126 под 1050 Ti): SD 1.5 + ControlNet + IP-Adapter FaceID, пакеты
вариантов фонов и портретов — конвейер схемы «живописный 2.5D».

## Риски и оговорки

- AGPL-3.0 или коммерческая лицензия; ~300 ★, бета.
- Работает локально (stdio).
- **Не задавать `COMFY_API_KEY`** — partner-модели тратят платные кредиты.
- Телеметрию comfy-cli выключить: `DO_NOT_TRACK=1`.
- На сервере — правила 1050 Ti (PyTorch cu126 ≤ 2.14, флаги `--force-fp32 --lowvram`).

## Как подключить

```
pip install comfy-mcp "comfy-cli>=1.14.0"
claude mcp add comfy-mcp -e COMFY_BIN=<путь> -e COMFYUI_URL=<адрес сервера> -e DO_NOT_TRACK=1 -- comfy-mcp
```
Адрес сервера в репозиторий не записывать.
