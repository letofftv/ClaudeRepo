# HyperFrames

- **Ссылка:** https://github.com/heygen-com/hyperframes
- **Что это:** видео пишется как HTML-страница (CSS, GSAP, Lottie, Three.js) и рендерится в MP4; сделан для ИИ-агентов
- **Найдено:** 2026-10-26, подборка по анимации на GitHub
- **Статус:** попробовать по частям — своя ферма уже делает то же самое (пересмотрено 2026-10-26 по техничке)

## Зачем фабрике

- **Обучающие видео с интерфейсами.** Интерфейсы платформ — это и есть HTML:
  в композицию можно вставить запись экрана или скриншоты и поверх добавить
  выноски, подсветку, зум, курсор и субтитры. Плагин умеет захватывать сайты.
  В самом репозитории (не в плагине, но можно скопировать) есть внутренние
  навыки ровно под это: большой курсор для UI-сцен (`oversized-cursor`) и
  правила наложения субтитров (`captions-overlay`).
- **Анимация и клипы.** Около 450 готовых блоков: переходы, титры, кинетическая
  типографика, графики, 3D, движения камеры. Основной навык прямо покрывает
  музыкальные клипы и вертикальные ролики.
- **Работа на сервере без человека.** CLI (`init`, `check`, `render`),
  детерминированный рендер: одинаковый вход — одинаковое видео, удобно для
  потока.
- **Использует видеокарту:** `render --gpu` — аппаратное кодирование
  (NVENC/VAAPI), `--browser-gpu` — GPU для захвата Chrome/WebGL.

## Риски и оговорки

- **Повторяет свою ферму фабрики** (сцены кодом → кадры в Chromium →
  ffmpeg). Заменять ферму не нужно — это два инструмента под одну задачу.
  Что стоит взять:
  - ~450 готовых блоков из реестра (Apache-2.0) — переходы, титры,
    кинетическая типографика, графики — как исходники сцен для фермы;
  - знания из навыков (`hyperframes`, `captions-overlay`, `oversized-cursor`);
  - **приём захвата кадров:** HyperFrames на GPU снимает кадры через
    BeginFrame в `chrome-headless-shell`, а не скриншотами. Гипотеза: это
    может ускорить GPU-путь фермы (сейчас ~8,5 с на кадр сцены) — проверить.
- Лицензия Apache-2.0, автор — HeyGen (крупная компания). ~72,9 тыс. ★.
- Плагин для Claude Code — это 7 навыков, **без хуков, без MCP-серверов и
  агентов** — в разы легче ECC.
- Навык `media-use` умеет брать озвучку, аватары и музыку из HeyGen (платный
  сервис, есть бесплатная квота). Есть и бесплатный путь через локальные
  инструменты — на фабрике выбирать его, чтобы не завязаться на подписку.
- Пересекается с Remotion: брать что-то одно. Есть навык переноса
  `remotion-to-hyperframes`.
- Нужны Node.js 22+ и FFmpeg.
- Субтитры: встроенный whisper.cpp по умолчанию собирается **только для CPU**
  с моделью `small.en` — для русского и для видеокарты см.
  `video/finds/whisper-cpp-cuda.md`. Есть встроенная альтернатива на CPU с русским —
  Parakeet TDT 0.6B v3 (`hyperframes models install parakeet`).

## Как подключить

На сервере фабрики (не в этой песочнице):

```
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
```

Проверка без плагина: `npx hyperframes init test-video && cd test-video && npx hyperframes render`.

Первая проба: короткий обучающий ролик по интерфейсу одной платформы —
запись экрана + выноски + субтитры, рендер с `--gpu`.
