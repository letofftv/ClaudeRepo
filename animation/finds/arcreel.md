# ArcReel

- **Ссылка:** https://github.com/ArcReel/ArcReel
- **Что это:** самохостируемая студия ИИ-видео: из текста или сценария — персонажи, раскадровка, клипы, монтаж
- **Найдено:** 2026-10-26, подборка по анимации (тема ai-animation)
- **Статус:** позже

## Зачем фабрике

Готовый конвейер «сценарий → видео» для ИИ-роликов и анимационных историй.
Управляется агентами (построен на Claude Agent SDK), разворачивается через
Docker Compose — подходит для домашнего сервера.

## Риски и оговорки

- **Лицензия AGPL-3.0** плюс доп. условия; для коммерческого использования
  авторы просят связаться с ними.
- Генерация идёт через облачных провайдеров (картинки, видео, озвучка) — нужны
  ключи и деньги. Поддержка локальных моделей на своей видеокарте в README не
  указана — тогда GPU сервера не пригодится.
- По умолчанию открывает порт на все сетевые интерфейсы — не выставлять в интернет.
- ~5,7 тыс. ★.
