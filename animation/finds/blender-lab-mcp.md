# Blender Lab MCP Server

- **Ссылка:** https://projects.blender.org/lab/blender_mcp (по данным сторонних сайтов)
- **Что это:** официальный MCP-сервер от Blender Lab — агент управляет Blender через его Python API
- **Найдено:** 2026-10-26, подборка по анимации
- **Статус:** позже (если фабрике понадобится 3D)

## Зачем фабрике

3D-анимация и сцены по описанию. Видеокарта сервера хорошо подходит для
рендера в Blender (Cycles).

## Риски и оговорки

- Выполняет сгенерированный Python без ограничений — может изменить или удалить
  данные проекта. Запускать в изолированной среде, не рядом с важными файлами.
- Требует Blender 5.1+. Порт по умолчанию 9876 конфликтует с неофициальным
  `ahujasid/blender-mcp` — не ставить оба.
- Даты релизов (v1.0 — апрель 2026) и детали взяты со сторонних сайтов, один из
  них продаёт конкурирующий сервер. Сверить с blender.org перед установкой.

## Как подключить

Пока не подключать.

## Что проверено

Ничего руками — только сторонние статьи и каталоги MCP.
