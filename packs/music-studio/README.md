# music-studio — пакет Claude Code для музыки и звука

Навыки для записи вокала под минусовку, сведения, мастеринга, замеров
громкости и работы с Ableton Live через MCP. Основа — публичные уроки
ведущих инженеров сведения и мастеринга, обзор MCP-серверов для DAW,
плагинов и открытых инструментов (2026-10-27). Подробности и источники —
[`research/2026-10-27-audio-production.md`](../../research/2026-10-27-audio-production.md).

## Что внутри

| Навык | Когда срабатывает |
|---|---|
| `vocal-recording` | подготовка минусовки, уровни, микрофон и комната, дубли, комп, редактура |
| `vocal-over-beat` | сведение русского вокала с готовой стерео-минусовкой: рецепт из 15 шагов |
| `mix-review` | «что не так с миксом»: что спросить, измерить, проверить, как советовать |
| `mastering` | мастеринг для стриминга, особый случай пережатой минусовки, QC-чеклист |
| `audio-measure` | замеры LUFS / true peak / PLR, сравнение с референсом, нормализация |
| `ableton-control` | выбор и безопасное подключение MCP-сервера для Ableton, пределы Live API |
| `audio-toolkit` | стемы, мастеринг по референсу, Pedalboard, анализ, таймкоды текста, MIDI, наброски |

Справочники (`references/`): приёмы мастеров со ссылками, карта плагинов
с бесплатными аналогами и заметками о покупке из России, цели громкости
площадок.

Скрипты (`skills/audio-measure/scripts/`) — только Python 3 и ffmpeg, без
пакетов; проверены на сгенерированных сигналах.

## Установка (на маке)

1. Прочитать навыки или прогнать пакет через SkillSpector — правило
   песочницы для любых навыков. В пакете только Markdown и три скрипта
   замеров, без хуков и MCP-серверов.
2. Поставить ffmpeg: `brew install ffmpeg`.
3. В Claude Code:
   ```
   claude plugin marketplace add letofftv/ClaudeRepo
   claude plugin install music-studio@clauderepo
   ```
   Обновление — `claude plugin marketplace update clauderepo`.

## С чего начать

- «Вот минусовка `beat.wav` — подготовь сессию для записи вокала.»
- «Свёл трек, сравни `mix.wav` с референсом `ref.wav` — что поправить?»
- «Сделай мастер для Яндекс Музыки и Spotify, вот микс.»
- «Подключи Ableton через MCP — у меня Live 12 Suite.»

## Ограничения

- Claude не слышит: советы опираются на замеры и описания владельца.
- Цифры из уроков мастеров — стартовые точки по поисковым сводкам их
  интервью; решения — на слух.
- Live API не умеет экспортировать, сохранять сет и видит не больше 128
  параметров стороннего плагина.
- Неизвестно (уточнить у владельца): редакция и версия Live, аудиоинтерфейс
  и микрофон, на каком компьютере идёт запись.
