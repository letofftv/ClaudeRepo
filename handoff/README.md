# Передача в фабрику

Пакеты из песочницы для Claude, который разрабатывает фабрику клипов (на маке).
Прямой связи между сессиями нет, поэтому канал такой:

1. **Песочница → фабрика.** Пакет лежит здесь, в публичном репозитории.
   Владелец вставляет в диалог фабрики короткий текст со ссылкой (ниже);
   Claude фабрики читает файл по ссылке сам.
2. **Фабрика → песочница.** В конце каждого пакета есть раздел «Ответ для
   песочницы». Claude фабрики заполняет его, владелец пересылает ответ в
   диалог песочницы — там его записывают в `CLAUDE.md` и карточки.

## Текст для вставки в диалог фабрики

```
Прочитай пакет из песочницы находок:
https://raw.githubusercontent.com/letofftv/ClaudeRepo/main/handoff/2026-10-26-clip-factory-4gb.md

Это оценка и план, а не приказ. Сверь его с текущим состоянием фермы,
отметь, что не сходится, и предложи, с какого теста начать на сценах из
брифа V3 «Города пробок». Ничего не устанавливай без моего подтверждения.
В конце заполни раздел «Ответ для песочницы» — я перешлю его обратно.
```
