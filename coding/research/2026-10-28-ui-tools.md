# Инструменты для интерфейсов: навыки Claude Code, библиотеки без сборки, панели мониторинга

Дата: 2026-10-28. Задача владельца: продумать удобный интерфейс, найти на
GitHub то, что поможет, сделать отдельный инструмент — создатель интерфейсов —
и собрать им интерфейс пульта с панелью актуального состояния сервера.

Итог:
- создатель интерфейсов — пакет [`coding/packs/ui-studio`](../packs/ui-studio/README.md);
- интерфейс пульта 0.3 — [`app/`](../../app/README.md);
- сценарии — [`app/design/ux.md`](../../app/design/ux.md).

## Как проверялось

Три параллельных исследования. Сеть песочницы пускала только
raw.githubusercontent.com, registry.npmjs.org и поиск. GitHub API, unpkg,
jsdelivr и сайты проектов были закрыты.

- **Пакеты из npm** скачаны и измерены (размер, gzip). Код просмотрен на
  `eval`, `<style>`, `innerHTML`, `style=`.
- **README и SKILL.md** прочитаны напрямую.
- **Пометки у каждого факта в JSON исследований:** [page] — прочитано,
  [search] — по выдаче поиска, [memory] — по памяти модели.
- **Руками проверены** только uPlot и иконки Lucide: оба встроены в набор
  ui-studio и работают в браузере под строгим CSP (подтверждено `ui_check.mjs`).

## 3. Панели мониторинга домашнего сервера

**Решение:** панель «Сервер» строим сами (стандартная библиотека, `/proc`,
nvidia-smi, docker, systemctl). Ни один готовый проект не работает с
телефона по-русски и не знает про наши задачи, WSL и порог видеопамяти 4 ГБ.
Для глубокой истории рядом ставится Beszel, для логов — Dozzle. На панели
пульта — только ссылки на них.

| Проект | Лицензия | Вердикт | Почему |
|---|---|---|---|
| [Beszel](../../common/finds/beszel.md) | MIT | **попробовать** | история 30 дней со средним/максимумом, графики по контейнерам, оповещения; агент для Windows видит настоящие 16 ГБ, диски C:/D: и температуры процессора |
| [Dozzle](../../common/finds/dozzle.md) | MIT | **попробовать** | логи контейнеров в браузере; ссылка «логи» из списка контейнеров |
| [LibreHardwareMonitor](../../common/finds/librehardwaremonitor.md) | MPL-2.0 | **попробовать** | датчики хоста Windows по HTTP (`/data.json`): температура процессора, которую WSL не видит |
| btop | Apache-2.0 | взять (образец, ssh) | лучший образец плотной подачи; удобен по ssh |
| Glances | LGPL-3.0 | позже | хороший REST, но история только в памяти (~1 ч), телефонный вид копирует терминал |
| Uptime Kuma, Gatus | MIT / Apache-2.0 | позже | внешний сторож на VPS Джарвиса: пульт шлёт «я жив», тишина → сообщение |
| Cockpit, Scrutiny, nvitop, dtop | разные | позже | администрирование, SMART (из WSL недоступен), GPU-TUI |
| Netdata | GPL-3.0+ | отклонено | 150–350 МБ ОЗУ, закрытый интерфейс со входом, навязывание облака |
| Dashdot, Homepage, Homarr, Dashy, gpustat, nvtop, Portainer, Grafana Node Exporter Full | разные | отклонено | стартовые страницы или TUI вместо панели; Grafana — тяжёлый стек (взяты только пороги) |

**Из исследования в панель пульта:**
- **Итог по худшему статусу.** Тревоги показываются с временем «с 12:03».
- **Гистерезис служб.** Одна или две неудачные проверки — «нет ответа», три подряд — «не отвечает» (как в Gatus).
- **Нагрузка во время задачи.** Высокая загрузка процессора при идущей задаче пульта — справка, а не замечание.
- **Нехватка памяти.** OOM в ядре — сразу красная тревога.
- **Готовность видеокарты.** Свободная видеопамять, температура, место, идущие задачи.
- **Пороги** (Node Exporter Full, Glances, Beszel):
  - ОЗУ: доступно меньше 20 % — замечание, меньше 10 % — проблема;
  - подкачка: 25 % и 60 %;
  - видеопамять: 90 % и 97 %;
  - GPU: 80 °C и 87 °C;
  - диск: меньше 30 ГБ или меньше 10 % — замечание, меньше 10 ГБ или меньше 5 % — проблема.
- **Пометка WSL2.** Память и «/» — это виртуальная машина; настоящее место — на `/mnt/c` и `/mnt/d`; процессы GPU в WSL недоступны.

## 4. Что из этого вошло в ui-studio

| Практика | Источник |
|---|---|
| Цикл: сценарии → экраны → токены → сборка → живые данные → проверка снимками | frontend-design, taste-skill |
| Бриф экрана: один вопрос, один вывод, действие в одно касание, доказательства рядом | taste-skill |
| Ловушки чистого JS (`[hidden]`, фокус при перерисовке, `<details>` и плеер, import map) | humane-agentic-design + опыт сборки пульта |
| Договор о ревью: место у каждого замечания, ≤15 замечаний, «не проверено» отдельно, важность | humane-agentic-design, OneRedOak |
| Фазы ревью и стресс-состояния (пусто, ×10, длинные русские слова, числа ru-RU) | OneRedOak, jakubkrehel |
| Признаки сгенерированного дашборда и что вместо | frontend-design, taste-skill |
| Касание 24/44 px, контраст самого бледного текста в обеих темах | humane-agentic-design |
| Палитра графиков и её проверка, анти-паттерны графиков | метод dataviz (Claude Code) |
| Статическая проверка CSP и контраста токенов в тестах | исследование библиотек |

- Поведение CLI-инструментов (agent-browser, impeccable `detect`) — не запускались.
- Скачивание браузеров Playwright и Chrome for Testing из России.
- Как ведут себя на сервере:
  - nvidia-smi в WSL: загрузка GPU, питание, список процессов;
  - агент Beszel для Windows на Pascal;
  - датчики LibreHardwareMonitor на этой плате.
- Статистика релизов и issues (GitHub API был закрыт).
