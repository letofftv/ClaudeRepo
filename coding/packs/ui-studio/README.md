# ui-studio — создатель интерфейсов

Пакет Claude Code для полного цикла веб-интерфейса: от сценариев до UI,
проверенного в настоящем браузере. Рассчитан на панели, дашборды и личные
инструменты. Работает без сборки и без CDN: файлы раздаются как есть и
проходят строгий CSP. Первый проект на нём — интерфейс «Домашнего пульта»
(`app/` в этом репозитории).

## Установка

```
claude plugin marketplace add letofftv/ClaudeRepo
claude plugin install ui-studio@clauderepo
```

Скриптам нужны Python 3.9+ и (для проверки) Node с Playwright:
`npm i -g playwright && npx playwright install chromium`. Вместо скачанного
Chromium можно указать установленный Chrome: `--channel chrome`.

## Что внутри

| Часть | Что делает |
|---|---|
| Навык `ui-studio` | весь цикл: сценарии → экраны → токены → сборка → живые данные → проверка |
| Навык `ux-scenarios` | участники (и ИИ-агенты), сценарии с частотой и критериями успеха, карта экранов, пять состояний экрана |
| Навык `visual-system` | токены, тёмная тема, шкалы, статусы, как избежать «шаблонного ИИ-вида» |
| Навык `dashboard-panels` | живые панели: итоговый статус, плитки, пороги, графики, тревоги, свежесть |
| Навык `ui-build` | оболочка, роутер, API, загрузка, формы, доступность — на чистых ES-модулях |
| Навык `ui-review` | автопроверка и разбор снимков по эвристикам |
| `scripts/tokens.py` | спецификация → `tokens.css` (OKLCH, подбор яркости под WCAG, отчёт по парам) |
| `scripts/ui_check.mjs` | Chromium: телефон/компьютер × светлая/тёмная; переполнение, ошибки JS/CSP, контраст, касания, подписи; PNG + отчёт |
| `scripts/scaffold.py` | `new` — новый проект; `sync`/`check` — обновить копию набора в проекте |
| `scripts/build_icons.py` | собрать спрайт из иконок Lucide |
| `kit/` | `base.css`, `components.css`, `ui.js` (DOM, формат чисел по-русски, API, роутер, опрос, тема, тосты, диалоги, перетаскивание), `charts.js` (спарклайн, полосы, графики uPlot с подсказкой и таблицей), 70 иконок, `gallery.html` |
| `references/` | эвристики удобства, тексты по-русски, проверенные библиотеки |
| `templates/` | шаблон `ux-scenarios.md`, спецификация токенов |

## Быстрый старт

```
python3 scripts/scaffold.py new ./my-panel --title "Моя панель"
python3 -m http.server -d ./my-panel 8000          # http://127.0.0.1:8000/
node scripts/ui_check.mjs --serve ./my-panel --routes "index.html"
```

Витрина компонентов — `kit/gallery.html`
(`node scripts/ui_check.mjs --serve kit --routes gallery.html` снимет её).

## Сторонние файлы

- uPlot 1.6.32 — MIT, `kit/vendor/uplot/LICENSE`.
- Иконки Lucide 1.63.0 — ISC, `kit/icons.LICENSE`.
- Палитра статусов и графиков — опорный экземпляр метода dataviz (Claude Code);
  контраст и различимость проверены его валидатором.

## Безопасность и вес

- Хуков нет, сеть не использует, ничего не отправляет.
- Скрипты запускаются только вручную.
- В каждую сессию добавляет описания шести навыков. Тексты навыков
  подгружаются, только когда задача про интерфейс.
