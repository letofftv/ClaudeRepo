# Живые панели

Если доступен навык `dataviz` (идёт с Claude Code), прочитать его перед первым
графиком: выбор формы, проверка палитры скриптом, анти-паттерны. Здесь —
то, что нужно именно для живых панелей.

## Первый экран отвечает на один вопрос: «всё ли в порядке?»

1. **Итоговый статус** — крупно, словом + иконкой + цветом: «Всё в порядке» /
   «Есть замечания (2)» / «Проблема: не отвечает Postgres». Причины — сразу под
   ним, самые серьёзные первыми, с временем «с 12:03».
2. **Плитки ключевых ресурсов** (4–6): значение, единица, контекст («из 4 ГБ»),
   полоса с порогом или спарклайн за 15 минут. Порог перешли — меняются полоса
   и рамка плитки, а не только цифра.
3. **Свежесть:** «обновлено 3 с назад» с пульсирующей точкой; если данные
   старше 3 интервалов опроса — плашка «нет свежих данных» и приглушение цифр.
4. Ниже — подробности: графики, службы, процессы, диски.

## Формы

| Данные | Форма |
|---|---|
| Текущее значение с лимитом (память, диск, VRAM) | плитка + полоса (`meter`), цвет полосы по порогу |
| Текущее значение и тренд (процессор, сеть) | плитка + спарклайн (`sparkline`) |
| История | линия 2 px, одна ось Y на график; разные единицы — разные графики |
| Много однородных значений (потоки ЦП, процессы) | строки с полосами (`.bars`) |
| Список служб | строка: точка статуса + имя + состояние словом + задержка/время |
| Тревоги | `.alert` по уровню, текст с цифрами, «с какого времени» |

Никогда: две оси на одном графике, круговая диаграмма для сравнения, цифра на
каждой точке, пунктирная сетка.

## Пороги (сервер с GPU — отправная точка, настраиваются)

| Метрика | Внимание | Проблема |
|---|---|---|
| Свободно на диске | <10% или <20 ГБ | <5% или <5 ГБ |
| Доступная память | <10% | <5% |
| Подкачка занята | >50% | — |
| Процессор, среднее за 5 мин | >90% | — |
| Температура GPU | ≥80 °C | ≥88 °C |
| Видеопамять | ≥90% | ≥98% |
| Служба не отвечает | — | сразу |

## Поведение тревог

- **Итог — худший статус**, а не среднее: одна упавшая служба делает панель
  красной.
- **Гистерезис служб:**
  - 1–2 неудачные проверки подряд — «нет ответа» (жёлтый);
  - 3 подряд — «не отвечает» (красный);
  - снимается после успешной.
- **Ожидаемая нагрузка — не тревога.** Если идёт своя задача, высокая
  загрузка процессора — справка («идёт задача»), а не замечание.
- **Нехватка памяти в ядре** (`oom_kill` в `/proc/vmstat`) — сразу красная
  тревога.
- **«Готовность»** — одна строка перед тяжёлой задачей: «Видеокарта
  свободна» или причины подождать (свободная видеопамять, температура,
  место на диске, идущие задачи).
- **Панель не сообщит о собственной смерти.** Для этого нужен внешний
  сторож на другой машине (Uptime Kuma или Gatus с push-проверкой).

## WSL2 и виртуальные машины

Память и «/» в WSL — это виртуальная машина: «/» показывает размер
виртуального диска, а не реальное место. Настоящее место Windows — на
`/mnt/c`, `/mnt/d`. Загрузка GPU и процессы GPU через nvidia-smi в WSL
ограничены, температура процессора не видна. Писать это на самой панели,
а не прятать.

## Глубже, чем панель

Своя панель отвечает на «всё ли в порядке сейчас». Для истории за 30 дней
и графиков по контейнерам рядом можно поставить Beszel, для логов — Dozzle.
На панели — ссылки на них, а не копия их функций.

## Обновление

- Опрос раз в 2–5 с, **пауза, когда вкладка скрыта** (`poll()` из `ui.js`).
- При перезапросе держать прошлую картинку (класс `.stale` на время загрузки),
  без скелетонов и прыжков вёрстки; скелетон — только при самом первом входе.
- История приходит столбцами (`t[]`, `cpu[]` …) — это формат uPlot; новые
  точки дописывать в конец, старые срезать по окну.
- Переключатель периода (15 мин / 1 ч / 6 ч / 24 ч) — один, над всеми
  графиками, и действует на все.

## Доступность

У каждого графика — свёрнутая «Таблица» (`chartTable`), подсказка не
единственный способ узнать значение. Легенда при двух и более сериях. Подписи
и значения — токенами текста, не цветом серии.

## Формат чисел

`fmt` из `ui.js`: `fmt.bytes` (1,5 ГБ), `fmt.rate` (1,2 МБ/с), `fmt.pct`
(37 %), `fmt.temp` (71 °C), `fmt.duration` (3 д 4 ч), `fmt.ago` («12 с назад»).
Десятичная запятая и неразрывный пробел перед единицей — уже внутри.
