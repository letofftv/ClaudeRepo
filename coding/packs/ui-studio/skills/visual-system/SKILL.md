# Визуальная система

## Токены — один источник правды

1. `python3 scripts/tokens.py --example > tokens.json` (в папке проекта).
2. Поправить: `accent_hue` (0–360, оттенок акцента в OKLCH; 255 — синий,
   150 — зелёный, 30 — оранжевый), `accent_chroma` (0.10 — сдержанно, 0.18 —
   ярко), `neutral_hue`/`neutral_chroma` (тёплый или холодный серый),
   `radius`, `density` (`compact` для плотных таблиц).
3. `python3 scripts/tokens.py tokens.json --out tokens.css` — отчёт по каждой
   паре цветов. FAIL исправлять в спецификации, не в CSS.

Что генерируется: `--bg --surface --surface-2 --surface-3 --border
--border-strong --text --text-2 --muted --accent --accent-hover --accent-text
--accent-soft --focus`, статусы `--ok --warn --serious --bad` с вариантами
`-text` (читаемый текст) и `-soft` (фон плашки), `--series-1…8` для графиков,
`--grid --axis`, шкалы `--s-1…9`, `--r-1…3`, `--fs-1…7`, `--fs-hero`, `--tap`.

Тёмная тема **выбрана, а не перевёрнута**: свои шаги яркости, свой акцент с
тёмным текстом на нём. Переключатель темы ставит `data-theme` на `<html>`;
без него работает системная настройка.

## Правила

- **Контраст:** текст ≥4,5:1, крупный (≥24 px или ≥18,7 px жирный) ≥3:1,
  элементы управления и метки графиков ≥3:1 (иначе — подписи значений или
  таблица). Проверяет `tokens.py`, на живой странице — `ui_check.mjs`.
- **Статус** — фиксированная шкала ok → warn → serious → bad, всегда с
  иконкой и словом; статусные цвета не используются для «просто серии 4».
  Текст статуса — токеном `-text`, сама заливка — только точки, полосы, иконки.
- **Один акцент.** Акцентом выделяется главное действие экрана и выбранное
  состояние; остальное — нейтральное. Иерархия — размером и насыщенностью
  текста, а не цветом.
- **Шрифт** — системный (`--font`), без внешних шрифтов. Шкала 12/13/15/17/20/
  24/32/48. Цифры в столбцах — `tabular-nums` (класс `.num`); крупные одиночные
  значения — пропорциональные.
- **Отступы** — только из шкалы 4-8-12-16-20-24-32-40-56. Внутри карточки —
  16, между карточками — 12–16, между секциями — 32.
- **Касание** — ≥44 px на телефоне (`--tap`), ≥24 px абсолютный минимум.
- **Движение** — 120–200 мс, только для смены состояния; уважать
  `prefers-reduced-motion` (уже в `base.css`).

## Как не сделать «шаблонный ИИ-вид»

- Настоящий текст и настоящие данные с первого макета: «Видеопамять 3,8 из 4 ГБ»,
  а не «Lorem ipsum» и «Metric 1».
- Никаких градиентов-«северных сияний», стекла, неоновых теней, эмодзи вместо
  иконок, случайных скруглений. Одна система иконок (Lucide в наборе).
- Не делать из каждого блока карточку с тенью: группировать отступами и
  заголовками; карточка — когда у блока своя граница смысла.
- Плотность по задаче: панель мониторинга плотнее лендинга; мелкий текст —
  приглушённым цветом, а не меньшим кеглем ниже 12 px.
- Пустые состояния, ошибки и загрузка оформлены так же тщательно, как норма.

Признаки сгенерированного дашборда — и что делать вместо:

| Признак | Вместо |
|---|---|
| плитки с «+12%» без базы сравнения | дельта только с названным периодом, иначе без дельты |
| сетка одинаковых карточек любой важности | главное крупнее и выше, второстепенное — строками |
| градиентный текст, неон, стекло | сплошной цвет токенов, тень только у всплывающего (диалог, тост) |
| три акцентных цвета на экране | один акцент; статусные цвета — только для статуса |
| декоративный график без осей и подписей | спарклайн как фон к цифре или полноценный график с осью и таблицей |
| всё по центру, огромные пустые шапки | выравнивание по левому краю, плотность по задаче |
| эмодзи вместо иконок | одна система иконок |

Для рабочих панелей шкала шрифтов спокойнее — шаг 1,125–1,2. Рамки — 1 px
с контрастом 1,1–1,3:1 к фону; это нормально, им не нужно 3:1.
