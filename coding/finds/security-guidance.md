# security-guidance

- **Ссылка:** https://github.com/anthropics/claude-plugins-official (плагин `security-guidance`)
- **Что это:** официальный плагин проверки безопасности в три слоя: предупреждения при правках, ревью диффа при остановке, ревью при commit/push
- **Найдено:** 2026-10-27, подборка лучшего для программирования
- **Статус:** попробовать — с выключенным ревью на остановке (`ENABLE_STOP_REVIEW=0`)

## Зачем фабрике

Для ботов и сервисов на VPS (Джарвис) и сервере: ловит опасные шаблоны
(~25 регулярных выражений) и проверяет коммиты.

## Риски и оговорки

- Apache-2.0. 6 хуков.
- На SessionStart ставит claude-agent-sdk через pip в venv
  `~/.claude/security/`.
- Дифф уходит только на api.anthropic.com (или своего провайдера).
- **Ревью на каждой остановке — ~$0,19 по прайсу**, а на подписке расходует
  лимиты; поэтому выключать его, а `/security-review` запускать вручную.

## Как подключить

```
/plugin install security-guidance@claude-plugins-official
```
и `ENABLE_STOP_REVIEW=0` в окружении.

## Что проверено
