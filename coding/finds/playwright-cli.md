# Playwright CLI

- **Ссылка:** https://github.com/microsoft/playwright-cli
- **Что это:** CLI Playwright с навыками для агентов — Claude открывает страницу, кликает, делает скриншоты и видео
- **Найдено:** 2026-10-27, подборка лучшего для программирования
- **Статус:** попробовать

## Зачем фабрике

Claude проверяет собственные HTML/Canvas-сцены и веб-интерфейсы, глядя на
них; запись видео с курсором (`video-start --cursor`). Microsoft сам советует
для агентов-программистов CLI + навыки вместо MCP — меньше токенов.

## Риски и оговорки

- Apache-2.0, ~14,7 тыс. ★. По умолчанию без окна (headless).
- **Та же семья, что Playwright MCP** из видеомонтажа
  (`video/finds/playwright-mcp-video.md`) — на каждой машине держать один:
  CLI для проверки своих сцен, MCP — если нужна запись чужих интерфейсов
  с агентом в браузере.

## Как подключить

```
npm i -g @playwright/cli@latest
playwright-cli install --skills
```
