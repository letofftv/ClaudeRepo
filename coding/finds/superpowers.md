# superpowers

- **Ссылка:** https://github.com/obra/superpowers
- **Что это:** набор из 15 навыков-методики: обсуждение → план → субагенты с ревью → TDD → проверка перед «готово» + worktree
- **Найдено:** 2026-10-27, подборка лучшего для программирования
- **Статус:** взять — единственный нужный набор методики

## Зачем фабрике

Дисциплина вайбкодинга без тяжёлых фреймворков: закрывает то, что дают
spec-kit, GSD и BMAD, но в десятки раз легче. Полезно для кода фермы,
Джарвиса и скриптов фабрики.

## Риски и оговорки
