# Web Interface Guidelines (Vercel)

- **Ссылка:** https://github.com/vercel-labs/web-interface-guidelines
- **Что это:** ~100 коротких проверяемых правил веб-интерфейсов (доступность, фокус, формы, касания, тёмная тема, тексты) с выводом `файл:строка`
- **Найдено:** 2026-10-28, исследование инструментов для интерфейсов
- **Статус:** взять — как источник правил для чек-листа ui-studio

## Зачем фабрике

Готовый список того, что проверять в своих интерфейсах до глаз: безопасные
зоны, касания, состояния форм, движение, i18n. Ложится на навык `ui-review`
и статические тесты пульта.

## Риски и оговорки

- **Лицензия.** MIT.
- **Сеть на каждом запуске.** Официальный навык (`web-design-guidelines` в vercel-labs/agent-skills) при каждом запуске скачивает правила с GitHub — лучше держать свою копию.
- **Правила под React и английский:** Title Case, «умные» кавычки, гидрация. Для русского интерфейса — адаптировать (ёлочки, ru-RU, без Title Case).

## Как подключить

Не ставить навык. При следующей доработке ui-studio — адаптированная копия
правил в `references/` с пометкой источника.
