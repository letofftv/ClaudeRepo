# axe-core

- **Ссылка:** https://github.com/dequelabs/axe-core
- **Что это:** стандартный движок автоматической проверки доступности (WCAG) прямо в странице
- **Найдено:** 2026-10-28, исследование инструментов для интерфейсов
- **Статус:** взять — для проверок, не для страниц

## Зачем фабрике

Полный аудит доступности своих интерфейсов: роли, подписи, порядок
заголовков, ARIA. `ui_check.mjs --axe` из ui-studio подключает его, если он
установлен. На этом же движке построены a11y в agent-browser и Lighthouse.

## Риски и оговорки

- **Лицензия.** MPL-2.0 — слабый copyleft на уровне файлов; в репозиторий не кладём.
- **Есть русская локаль.**
- **Нужен eval.** Поэтому работает только в тестовом контексте с `bypassCSP`; на страницы пульта не класть.
- **Размер.** 177 КБ gzip.

## Как подключить

```
npm i -g axe-core          # или локально в папке проверки
node coding/packs/ui-studio/scripts/ui_check.mjs --url … --routes … --axe
```
