# Context7

- **Ссылка:** https://github.com/upstash/context7
- **Что это:** MCP-сервер с актуальной документацией библиотек под нужную версию — 2 инструмента
- **Найдено:** 2026-10-27, подборка лучшего для программирования
- **Статус:** взять

## Зачем фабрике

Меньше выдуманных API: ffmpeg-обёртки, Playwright, grammY (боты Telegram),
pgvector, Docker SDK, Remotion и т.д. Всего 2 инструмента —
`resolve-library-id` и `query-docs`.

## Риски и оговорки

- MIT, ~64 тыс. ★.
- Удалённый сервер Upstash: запросы уходят к ним — **не вставлять секреты в
  запросы**. Ключ необязателен (бесплатный ключ даёт больше лимитов).

## Как подключить

```
/plugin install context7@claude-plugins-official
```
