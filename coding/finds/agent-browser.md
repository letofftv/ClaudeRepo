# agent-browser (Vercel)

- **Ссылка:** https://github.com/vercel-labs/agent-browser
- **Что это:** CLI-браузер для агента: снимки с номерами элементов, сравнение снимков с эталоном, тёмная/светлая тема, аудит доступности со встроенным axe
- **Найдено:** 2026-10-28, исследование инструментов для интерфейсов
- **Статус:** попробовать — против уже выбранного [Playwright CLI](playwright-cli.md), оставить один

## Зачем фабрике

Интерактивный просмотр своих страниц Claude-ом: открыть, нажать, сравнить с
прошлым снимком, проверить доступность. По README работает офлайн и под
строгим CSP — как раз пульт и сцены фермы. `ui_check.mjs` из ui-studio
закрывает пакетную проверку, а этот CLI — разбор вживую.

## Риски и оговорки

- **Лицензия.** Apache-2.0, 44,7k★, активная разработка (0.40.0 — 2026-10-27).
- **Выполнение кода.** `eval` выполняет JS в странице.
- **WebMCP включён по умолчанию.** Описания инструментов от страницы — недоверенные, отключать `--no-webmcp`.
- **Телеметрия.** В README не упомянута; исходники не проверялись.
- **Браузер.** Качает Chrome for Testing (доступность из России не проверена) или берёт установленный Chrome.
- **Пересечение.** Дублирует Playwright CLI.

## Как подключить

На маке, после проверки SkillSpector:

```
npm i -g agent-browser && agent-browser install
```
