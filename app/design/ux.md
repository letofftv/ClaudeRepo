# Домашний пульт — сценарии и экраны

Дата: 2026-10-28. Сделано навыком `ux-scenarios` пакета ui-studio
(`coding/packs/ui-studio`). Основа: просьба владельца сделать удобный
интерфейс с панелью актуального состояния сервера, разбор интерфейса 0.2
(одно действие = 4 вкладки, результат = лог ffmpeg, нет живого состояния),
возможности API.

## Навигация

Пять разделов. На телефоне это нижняя панель с центральной кнопкой «+», на компьютере — боковая:

| Раздел | Адрес | Назначение |
|---|---|---|
| Обзор | `#/` | итог, тревоги, ресурсы, идущие задачи, свежие результаты, быстрые действия |
| Сервер | `#/server` | живая панель: ресурсы, графики 15 мин–24 ч, видеокарта, диски, службы, контейнеры, процессы, версия |
| + Запуск | `#/run` | загрузка (перетаскиванием или выбором), подсказки по типу файла, все инструменты, файлы |
| Задачи | `#/jobs`, `#/jobs/<id>` | список и карточка задачи: результат первым, прогресс, «Дальше →», лог свёрнут |
| Библиотека | `#/library?tab=…` | каталог находок, бесплатные ресурсы, стартовые наборы — один поиск |

Настройки (`#/settings`) открываются из шапки:
- тема;
- выход;
- версия;
- «Обновить сейчас».

## Экраны

### Обзор — `#/`
- **Цель:** ответить «всё ли в порядке» и показать, что требует внимания.
- **Сценарии:** S1, S3, S4, S9, S10, S14.
- **Данные:** `/api/metrics` раз в 3 с, `/api/jobs` раз в 3 с.
- **Действия:**
  - перейти к тревоге;
  - открыть задачу;
  - быстрые действия «Загрузить файл» и «Проверить громкость».
- **Состояния:**
  - загрузка — скелетон только при первом входе;
  - пусто (нет задач) — подсказка «бросьте файл»;
  - ошибка API — плашка с текстом;
  - нет связи — «Нет связи с сервером, данные N с назад», цифры приглушены;
  - норма — зелёный итог «Всё в порядке».

### Сервер — `#/server`
- **Цель:** полная картина и история.
- **Сценарии:** S2–S5.
- **Данные:**
  - `/api/metrics` раз в 3 с;
  - `/api/metrics/history?range=` при смене периода, новые точки дописываются из живых данных.
- **Блоки:**
  - итог и тревоги;
  - плитки: ЦП, память, VRAM, GPU, температура, диски, сеть;
  - период 15 мин / 1 ч / 6 ч / 24 ч одним переключателем;
  - графики: ЦП, память, GPU и VRAM, температура GPU, сеть, диск — у каждого таблица;
  - потоки ЦП;
  - видеокарта подробно;
  - диски;
  - службы и контейнеры;
  - топ процессов по ЦП и памяти;
  - система: WSL, время работы, версия, обновление.
- **Состояния:**
  - нет видеокарты — «nvidia-smi не найден» в плитке, без ошибки страницы;
  - Docker недоступен — «Docker не отвечает»;
  - службы не настроены — подсказка, как добавить их в `hub.json`;
  - история пустая после запуска — «История копится: N точек».

### Запуск — `#/run`
- **Цель:** от файла к результату за 2 касания.
- **Сценарии:** S6–S8.
- **Блоки:**
  - зона загрузки;
  - после загрузки — лист «Что сделать с файлом» с инструментами под его тип;
  - переключатель «Инструменты | Файлы»;
  - инструменты по группам с поиском; недоступные свёрнуты с причиной;
  - файлы: тип, размер, «Что сделать», удалить.
- **Форма запуска** — нижний лист:
  - поля по типам;
  - выбор файла — только подходящие типы, свежие сверху, без путей.
- **Состояния:** нет файлов — зона загрузки с текстом; инструмент недоступен — причина и что поставить.

### Задачи — `#/jobs`, `#/jobs/<id>`
- **Список:**
  - сверху идущие, с процентом и временем;
  - ниже готовые — со статусом словом.
- **Карточка задачи:**
  - заголовок, статус, время;
  - результат первым: отчёт громкости или сравнения карточкой с цифрами, медиа — плеером или картинкой;
  - файлы с «Показать / Скачать / Дальше →»;
  - параметры;
  - лог свёрнут; при ошибке — развёрнут и показывает конец;
  - «Отменить», «Повторить», «Удалить».
- **Место:** размер папки задач, «Удалить задачи старше 30 дней».

### Библиотека — `#/library`
- Переключатель «Каталог | Ресурсы | Наборы» и общий поиск.
- Фильтры чипами: направление и статус; доступ из России; «локально».
- Карточки:
  - ссылка;
  - статус;
  - команда установки с «Копировать».

### Вход
Поле токена, пояснение «HUB_TOKEN из ~/.config/hub/env на сервере», кнопка «Войти». Ошибка — «Токен не подошёл».

## Визуальная система

- `app/design/tokens.json` → `app/static/tokens.css` (`tokens.py`). Все пары текст/фон проходят WCAG.
- Графики:
  - не больше двух серий на график: слоты 1–2, синий и оранжевый;
  - валидатор dataviz: в светлой теме различимость ΔE 24,7, контраст ≥3:1; в тёмной — все проверки PASS.
- Статусы: ok, warn, crit с иконкой и словом.

## Критерии приёмки

- [ ] Телефон 390 px: итоговый статус и тревоги видны на Обзоре без прокрутки.
- [ ] Данные Обзора и Сервера обновляются каждые 3 с, пауза при скрытой вкладке.
- [ ] Метка «обновлено N с назад»; через 15 с без данных появляется «Нет свежих данных».
- [ ] Брошенный в окно файл загружается, после чего показаны подходящие инструменты.
- [ ] У задачи с замером громкости результат — карточка с LUFS/TP/PLR, а не лог.
- [ ] Идущая задача показывает процент, где ffmpeg его сообщает.
- [ ] Из результата можно запустить следующий инструмент, не выбирая файл заново.
- [ ] `ui_check.mjs`: 0 FAIL на телефоне и компьютере в светлой и тёмной теме на всех разделах.
- [ ] Все тексты по-русски, единицы через неразрывный пробел.
